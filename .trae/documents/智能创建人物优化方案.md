# 智能创建人物优化方案（混合方案）

## 功能概述

### 功能 1: 排除已创建角色
在智能创建人物的角色列表中，过滤掉已经创建过的人物。

### 功能 2: 智能添加更多图片到人物
在人物详情页提供手动入口，使用相似度阈值滑块搜索匹配的新图片并添加到人物。

## 第三部分: 智能添加更多图片到人物

### 3.1 新增组件 SmartAddToPersonModal
**文件**: `src/components/modals/SmartAddToPersonModal.tsx`

**功能**:
- 显示人物信息（名称、头像）
- 相似度阈值滑块（0.01 - 0.5）
- 匹配图片网格（虚拟滚动）
- 已关联的图片显示标记，不可重复添加
- 确认按钮添加选中的图片

**Props**:
```typescript
interface SmartAddToPersonModalProps {
  person: Person;
  files: Record<string, FileNode>;
  resourceRoot: string;
  cachePath: string;
  language: 'zh' | 'en';
  clipSettings: { enabled: boolean; modelName: string };
  onConfirm: (newFileIds: string[]) => void;
  onClose: () => void;
  t: (key: string) => string;
}
```

**核心逻辑**:
1. 使用 `person.characterTagIndex` 调用 `clipSearchByCharacterTag` 搜索匹配图片
2. 过滤掉已关联的文件（通过检查 `file.aiData.faces` 中是否有该 personId）
3. 显示可添加的新图片列表
4. 用户调整阈值后重新搜索
