# 安卓端网络总览视图实现计划

## Context

当前安卓端左侧面板的"网络"分区（`NetworkSection`）点击后只在 sidebar 内展开桌面端根目录文件夹列表（垂直列表），点击列表项进入单个文件夹浏览。但安卓端打开软件后主内容区显示的是本地相册总览视图（`FoldersOverview` 卡片网格），两种交互模式不一致。

本次改动将"网络"分区改为：点击头部时切换主内容区到**网络总览视图**（`lan-folders-overview`），复用 `FoldersOverview` 组件以卡片网格形式展示桌面端根目录文件夹，与本地相册总览视觉/交互一致。文件夹卡片利用 LAN browse API 已返回的 `preview_images` 显示封面图。

## 方案概述

新增 `lan-folders-overview` viewMode，复用现有 `FoldersOverview` 组件，传入 `roots={lanRoots}`。关键改造点：

1. `NetworkSection` 由"sidebar 内展开列表"改为"点击头部导航到 overview"（仿 `PeopleSection` 模式）
2. `FolderCard` 补充 LAN 封面图加载分支（`lan://` 前缀短路到 `lanClientApi.getThumbnailUrl`）
3. `folderItemToFileNode` 利用 `preview_images` 设置 `coverImagePath` 与 `imageCount`
4. `handleNavigateUp` / `handleAndroidBackPress` / 刷新逻辑补齐 LAN 分支

### 3. `src/components/lan-client/lanClientApi.ts` — folderItemToFileNode 补字段

`folderItemToFileNode`（行 224）利用 `BrowseItem.preview_images` 和 `size`：

```typescript
private folderItemToFileNode(item: BrowseItem): FileNode {
  const remotePath = item.path;
  const coverRemote = item.preview_images?.[0];
  return {
    id: generateId(remotePath),
    parentId: null,
    name: item.name,
    type: FileType.FOLDER,
    path: 'lan://' + remotePath,
    remotePath,
    source: 'lan',
    children: [],
    tags: [],
    coverImagePath: coverRemote ? 'lan://' + coverRemote : undefined,
    imageCount: typeof item.size === 'number' ? item.size : 0,
  };
}
```

### 4. `src/components/FoldersOverview.tsx` — FolderCard 支持 LAN 封面

在文件顶部 import `lanClientApi`。在 `FolderCard` 的封面加载 `useEffect`（行 106-139）开头插入 LAN 短路：

```typescript
useEffect(() => {
  if (!(isInView || wasInView)) return;
  if (!effectiveCoverPath) return;

  // LAN 封面：直接生成 URL，不走 Tauri getThumbnail
  if (effectiveCoverPath.startsWith('lan://')) {
    const cache = getGlobalCache();
    const cached = cache.get(effectiveCoverPath);
    if (cached) { setCoverSrc(cached); return; }
    const url = lanClientApi.getThumbnailUrl(effectiveCoverPath.slice('lan://'.length));
    cache.set(effectiveCoverPath, url);
    setCoverSrc(url);
    return;
  }

  if (!resourceRoot) return;
  // ...原有逻辑保持不变
}, [isInView, wasInView, effectiveCoverPath, ...]);
```

同时调整初始 `coverSrc` state（行 75-79）让 LAN 路径也能从缓存命中（`getGlobalCache().get` 对 `lan://` key 同样有效，无需改）。

### 5. `src/App.tsx` — 核心接线

**a. 新增 `handleNavigateNetworkHome`**（仿 `handleNavigateHome`，行 2051）：

```typescript
const handleNavigateNetworkHome = useCallback(() => {
  if (!lanConnected) { handleOpenLanSettings(); return; }
  pushHistory('__lan_folders_root__', null, 'lan-folders-overview', '', 'all', [], null, 0);
```

**b. 新增 `handleLanRefresh`**（LAN 总览下拉刷新，不复用 `handleRefresh`）：

```typescript
const handleLanRefresh = useCallback(async () => {
  if (!lanConnected) return;
  setLanLoading(true);
  try {
    const { folders } = await lanClientApi.browseToFolderNodes('/');
    const newFiles: Record<string, FileNode> = {};
    const newRootIds: string[] = [];
    for (const f of folders) { newFiles[f.id] = f; newRootIds.push(f.id); }
    setState(s => ({ ...s, files: { ...s.files, ...newFiles } }));
    setLanRoots(newRootIds);
  } catch (err) { console.error('[LAN] Refresh failed:', err); }
  finally { setLanLoading(false); }
}, [lanConnected, setState]);
```

## 复用的现有机制

- `pushHistory`（`useNavigation.ts:23`）— viewMode 已参数化，直接传 `'lan-folders-overview'`
- `handleNavigateNetworkFolder`（`App.tsx:911`）— 进入 LAN 文件夹浏览，复用为卡片点击回调
- `lanClientApi.getThumbnailUrl`（`lanClientApi.ts:190`）— 生成 LAN 缩略图 URL

## 验证

1. **构建**：`npm run build` 确认 TypeScript 编译无错误（viewMode 类型扩展 propagated）
2. **安卓端连接桌面端**后，左侧"网络"分区点击 → 主内容区切换到卡片网格视图，显示桌面端根目录文件夹
3. **封面图**：文件夹卡片显示桌面端 `preview_images` 第一张缩略图（通过 `/api/thumbnail`）
4. **进入文件夹**：点击卡片 → 进入该 LAN 文件夹浏览模式（`handleNavigateNetworkFolder`）
5. **返回**：在 LAN 文件夹内按返回键/↑ → 回到 `lan-folders-overview`；在 `lan-folders-overview` 按返回键 → 落入退出确认
6. **下拉刷新**：在 `lan-folders-overview` 下拉 → 重新拉取桌面端根目录
7. **未连接**：未连接时点击"网络" → 跳转设置面板
8. **桌面端不受影响**：`isAndroidPlatformCached()` 守卫确保桌面端无 NetworkSection
