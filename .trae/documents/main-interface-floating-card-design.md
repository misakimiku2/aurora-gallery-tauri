# 主界面「悬浮卡片」设计规范

> 基于 2026-07-19 会话最终确认的方案

---

## 一、整体布局结构

```
┌──────────────────────────────────────────────────────┐
│                 标签页栏 (bg-main)                     │  ← 紧贴窗口顶部，与底色一致
├──────────────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────────────┐ │  ← 大卡片 m-2, 仅底部三边圆角
│ │  左侧面板  │  顶部工具栏 + 文件区域  │  右侧面板  │ │     活跃标签最左侧时: 左上角直角
│ │  (bg-panel)│  (主内容区 bg-content)  │ (bg-panel) │ │     否则: 四角全圆角 (rounded-xl)
│ └──────────────────────────────────────────────────┘ │
│                       m-2 rounded-b-xl               │
└──────────────────────────────────────────────────────┘
```

- **窗口底色**（bg-main）: `#e5e5e5` / 深色 `#1a1a1a` — 也是标签页栏背景
- **大卡片**（bg-content）: `#ffffff` / 深色 `#262626` — 包裹三个工作区
  - 与窗口边缘有 8px 间距 (`m-2`)
  - 底部三边始终圆角
  - 左上角: 活跃标签在最左时直角，否则圆角
- **左右面板**（bg-panel）: `#f7f7f7` / 深色 `#2a2a2a` — 浅灰色，与主内容区通过颜色区分
- **bg-surface**（hover/卡片表面）: `#f3f4f6` / 深色 `#3a3a3a`
- **border-subtle**（淡边框）: `#e5e7eb` / 深色 `#404040`

## 二、无分隔线视觉层次体系

采用 **背景色微差** + **间距** + **圆角卡片化** 替代传统分割线：

| 层次 | 浅色模式 | 深色模式 | 作用 |
|------|----------|----------|------|
| 窗口底色 (bg-main) | #e5e5e5 | #1a1a1a | 最底层，间隙色 |
| 大卡片 (bg-content) | #ffffff | #262626 | 主工作区 |
| 侧面板 (bg-panel) | #f7f7f7 | #2a2a2a | 左右侧栏，微差区分 |
| hover/卡片面 (bg-surface) | #f3f4f6 | #3a3a3a | 按钮hover、内部卡片 |
| 淡边框 (border-subtle) | #e5e7eb | #404040 | 仅必要的弱边框 |

### 分隔方案
- 主区域之间 = 颜色差异（bg-content vs bg-panel）+ 直角拼接（无间距）
- 窗口边缘 = 8px 间隙（通过大卡片 m-2 实现）
- 内部分组 = 弱阴影 + 圆角 + bg-surface 卡片
- 列表/网格项 = 间距 + hover:bg-surface
- 完全移除传统 `border-r` / `border-l` 分隔线

## 三、各组件设计要点

### 3.1 标签页栏 (TabBar)
- 背景: `bg-main`（与窗口底色一致）
- 位置: 窗口最顶部，独立于大卡片之外
- 高度: 41px
- 活跃标签页紧贴下方大卡片顶部
- 活跃标签为最左侧时，大卡片左上角直角，视觉上与标签栏无缝衔接

### 3.2 顶部工具栏 (TopBar)
- 背景: `bg-content`（与大卡片主区域一致）
- 高度: 56px (h-14)
- 完全扁平，无边框阴影
- 搜索框默认: `bg-surface border-transparent`（可辨识浅灰色）
- 搜索框聚焦: `bg-surface border-subtle`
- 搜索框激活（有内容）: `bg-surface border-blue-500 shadow-sm`
- 按钮: `hover:bg-surface` 圆角

### 3.3 面包屑导航 (Breadcrumb)
- 高度: 30px
- 背景: `bg-content backdrop-blur`
- 文字: `text-xs text-gray-500/400`
- 粘贴于顶部工具栏下方

### 3.4 左右侧面板 (Sidebar / MetadataPanel)
- 背景: `bg-panel`（浅灰色）
- 圆角: 由外层大卡片统一控制，自身无圆角
- 展开/收起: `width` 过渡动画 300ms ease-out
- 内部 hover: `hover:bg-surface`
- 选中态: 根据场景使用蓝色或主题色

### 3.5 文件区域 (FileGrid)
- 背景: `bg-content`（白色）— 无背景色隔断
- 卡片项: `bg-surface`（预览图下方信息区）
- 分组标题: `bg-content/80 backdrop-blur-sm border-b border-subtle`
- 容器内边距: 24px（由布局 worker 内部 PADDING 控制，外层无 p-4）

### 3.6 弹窗/下拉菜单/浮动面板
- 保持原有独立层级，不跟随大卡片背景
- 可保留阴影和分隔线以实现视觉浮层效果

## 四、CSS 令牌对照表

| Tailwind 类 | 浅色值 | 深色值 | 用途 |
|-------------|--------|--------|------|
| `bg-main` | #e5e5e5 | #1a1a1a | 窗口底色、标签栏 |
| `bg-content` | #ffffff | #262626 | 大卡片、主内容区 |
| `bg-panel` | #f7f7f7 | #2a2a2a | 左右面板 |
| `bg-surface` | #f3f4f6 | #3a3a3a | hover态、内部卡片 |
| `border-subtle` | #e5e7eb | #404040 | 弱边框 |

## 五、关键约束与注意事项

1. **大卡片圆角逻辑**（App.tsx 中实现）:
   - 始终 `rounded-tr-xl rounded-bl-xl rounded-br-xl`
   - 当 `isLeftmostTab`（活跃标签在最左）时: `rounded-bl-xl rounded-br-xl rounded-tr-xl`（左上直角）
   - 当非最左标签时: `rounded-xl`（四角全圆）

2. **面包屑高度**: 固定 30px (`h-[30px]`)

3. **侧栏面板展开动画**: 只过渡 `width`，不与 `margin` 绑定（避免鬼影间隙）

4. **大卡片 overflow**: `overflow-hidden` 确保内部内容不跑出圆角范围

5. **深色模式**:
   - 窗口底色 #1a1a1a 比主内容 #262626 更深，形成明显明暗层次
   - 侧面板 #2a2a2a 比主内容稍亮，维持与浅色模式一致的对比关系
