# 内存占用治理计划

## Context（诊断结论）

- **编辑中 1.5GB**：GPU 进程 1.32GB ← 位图泵全幅渲染链（拖滑杆/渐变时 ~10Hz 全幅 compose → 96~144MB RGBA IPC → putImageData → GPU 上传，`EditorCanvas.tsx:1539-1621`）；原生进程 592MB ← 引擎文档 + 50 步历史快照（8GB 字节预算形同虚设，`prefs.rs:542/607`）。
- **关闭编辑后 ~1GB**：Rust 侧 `EditorManager::close()` 不清 `magnetic` 快照（持整份文档 Arc）与 `session.clipboard`（`editor/src/lib.rs:293-296`）；前端 offscreen 画布不归零；隐藏编辑 tab 整套位图保留；WebView2 GPU/管理器进程默认不向 OS 归还内存（零调优）；图库侧对比模式 mipmap 缓存无淘汰、AVIF/JXL 整文件 base64 常驻 blobCache。

用户已拍板：①交互期降分辨率预览（PS 同款）②历史预算 2048MB/50 步 ③做 WebView2 MemoryUsageTargetLevel。

## A. 交互期降载渲染（GPU 1.3GB 主解药）

1. `src/components/editor/editorStore.ts`：`EditorRuntime` 加 `interactiveRender: boolean`；导出 `setInteractiveRender(tabId, on)`（updateSession 置位并 notify）。
2. `src/components/editor/EditorCanvas.tsx` bitmapPump（:1539-1621）：新增 `useSession` 订阅 `s.runtime.interactiveRender` 经 ref 传入泵；交互期把现有 `RASTER_PIXEL_BUDGET=36MP` 换成视口预算（`wrapRef` CSS 尺寸 × dpr²，钳 ≤4MP）→ 走现有 `editorRender(docId, maxW, maxH)` 降采样通路（`render_reduced` 已存在）；交互结束/最终提交后 revision 推进 + flag=false → 自动全分辨率重渲。灰度蒙版查看分支共用同一 rs 计算。
3. 接入点：
   - `src/components/editor/panels/AdjustmentProps.tsx` `useAdjustEmitter`（:102-147）：首个 `emit` → `setInteractiveRender(true)`；`flushNow` → 先 `setInteractiveRender(false)` 再 flush（最终 coalesce 提交触发全分辨率渲染）。
   - `EditorCanvas.tsx` 渐变拖动（`gradGestureRef`，:2076/:2658 一带）：手势开始 begin、结束 end。

## B. 历史预算 2GB（编辑中原生进程 GB 级增长）

`editor/src/lib.rs` `EditorManager::new()`（:147-149）：`self.session.execute("prefs.set", json!({"values": {"performance.memoryUsageMb": 2048}}))`（`Session::execute` 同款用法已在 :287；`prefs_set` 无文档依赖，`apply_prefs` 会同步预算到已开文档，`prefs.rs:2062-2094`；`historyStates` 保持 50）。不碰 photocraft-vendor 默认值。

## C. 关闭残留清理（关闭后不回落的可修部分）

1. `editor/src/lib.rs` `close()`（:293-296）：加 `self.magnetic = None; self.session.clipboard = None;`（clipboard 是 pub 字段，`engine/src/lib.rs:479`）。
2. `src/components/editor/editorStore.ts` `disposeSession`（:494-502）：置 null 前 `offscreen.width=0/height=0` 归零释放位图 backing，再 `offscreen=null`。
3. `src/components/editor/panels/LayersPanel.tsx`：导出 `clearEditorThumbCaches(docId)`（删 `thumbCache` 中 `${docId}:` 前缀条目，:17-25）；在 `EditorShell.tsx` 卸载 cleanup（:64-68，disposeSession 前）取 `getSession(tabId)?.docId` 调用——避免 editorStore→LayersPanel 循环导入。

## D. 隐藏编辑 tab 释放位图（多标签 N×96MB）

`EditorCanvas.tsx`：`useEffect` 订阅 `isActive`——false 时归零并置 null `runtime.offscreen`、`bitmapKeyRef.current=''`；true 时同样重置 key 并 `void bitmapPump()` 强制重渲（会话状态/历史不动，重新激活一次全幅渲染）。

## E. 信息面板取色消除 GPU 全纹理回读

`src/components/editor/panels/NavigatorInfoPanel.tsx`（:108-142）：rAF 轮询里记录上次取色 key（`${px},${py},${revision},${rasterScale}`），指针未动且 revision 未变则跳过 `getImageData(1,1)`——闲置时零回读，原精度不变。

## F. WebView2 MemoryUsageTargetLevel（关闭后 WebView2 侧归还内存）

1. `src-tauri/src/window_commands.rs`：新命令 `set_webview_memory_target(low: bool)`——照抄 `capture_window_snapshot`（:131-215）模板：`with_webview` → `webview.controller()` → `CoreWebView2()` → `cast::<ICoreWebView2_19>()` → `SetMemoryUsageTargetLevel(COREWEBVIEW2_MEMORY_USAGE_TARGET_LEVEL_LOW/NORMAL)`（绑定已确认存在于 webview2-com-sys 0.38.2）；cast 失败（Runtime <1.0.2903）静默 Ok。注册进 `lib.rs` invoke_handler。
2. `src/App.tsx`：tab 有 `isEditorMode`（:785）；useEffect 监听 `state.tabs.filter(t=>t.isEditorMode).length`——0→`invoke('set_webview_memory_target',{low:true})`，>0→false。

## G. 图库侧缓存修正

1. `src/hooks/useImageLoader.ts`：effect 开头按当前 `imageFiles` id 集淘汰 `imagesCache` 不在列表的条目（original+mipmaps 整组释放）——对比模式缩小选区即回落。
2. `src/components/ImageViewer.tsx` blobCache（:155-184）：JXL/AVIF 的 base64 data URL 改为 Blob→`URL.createObjectURL` 存储；`evictBlobCache` 淘汰时对 `blob:` 前缀条目 `URL.revokeObjectURL`。消灭最坏 ~500MB 的 JS base64 字符串常驻。

## 不做（记录原因）

- `AppState.files` 无界合并：标量数据，10 万级才 ~50-100MB，改动风险大 → 后续。
- dominant colors/解码背压：瞬时峰值非本次主诉 → 后续。
- `editor_render` 拷贝优化：收益微小。

## 验证

1. `npm run build`（tsc 0）+ `npx vitest run`（308 全绿）；`cd src-tauri && cargo check`。
2. `npm run tauri dev` 实测（任务管理器观察）：
   - 打开大图（≥20MP）编辑 → 拖色阶滑杆数秒：GPU 进程交互期上传量级应从 ~96MB/帧 降到 ~10MB/帧，松手画面立即恢复清晰；
   - 渐变拖动同理；灰度蒙版查看正常；
   - 信息面板 RGB 随指针移动正常刷新；
   - 关闭编辑 tab：原生进程回落（magnetic/clipboard 已清）、WebView2 GPU/管理器进程回落（memory target 生效；旧 Runtime 则静默跳过）；
   - 多开 2 个编辑 tab 切走再切回：位图释放且重渲正常、图层/历史完整；
   - 编辑一张图 Ctrl+S 保存 + 重开伴生 PSD 正常（历史预算变更不影响保存链路）；
   - 对比模式选 4 张大图后缩小选区：内存回落；JXL/AVIF 图浏览正常。
