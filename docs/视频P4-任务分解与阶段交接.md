## §2 目标架构（最终态）

```
桌面端本地播放
  ├─ Chromium 能解的编码（H.264/VP8/VP9/AV1…）→ WebView2 <video>（现状保留）
  └─ 其余一律 → libmpv 嵌入（popup 顶层窗口，跟随主窗口同步）  ← 播原文件，零转码

LAN 手机端播放
  ├─ 手机能解的容器 + 编码 → HTTP Range 直读原文件（现状 direct）
  └─ 其余 → 服务端 HLS 流式（EVENT 分片，不落全量、秒开、原生 seek）
```

**两条腿互不依赖**，可并行推进。

**最终收益**：
- 桌面端：`video_remux` 桌面端路径（remux 作业 / LRU / 4 GiB 预算 / 等待态 UI）**整体删除**
- LAN 端：从「等 102 秒」变成「约 1 秒起播」

## §4.5 S1 落地记录（2026-10-20，`240f54ccf`）—— 交给 S2 的现场

  容器表 `WEB_DECODABLE_VIDEO_EXTENSIONS` **保留**（抽帧 P1.5-A 还在用）。
- **分派规则**（ImageViewer `shouldUseMpv`）：
  ① 容器不可解 → mpv；② 容器可解 + 编码已知不可解 → mpv；
  ③ 容器可解 + 编码未知 → 试 `<video>`，onError 兜底 mpv（`mpvFallback`，只兜一次）。
- **mpv_player.rs 正式版**：命令 `mpv_player_open/set_rect/state/command/stop`。
  位置 = 前端 rect（**已按 `devicePixelRatio` 换算物理像素**）+ Rust `ClientToScreen`；
  `WS_POPUP` + owner + `WS_EX_NOACTIVATE`（点击不抢焦点，键盘留在 WebView）。
- **窗口跟随**：JS 侧 Tauri `onMoved`（移动）+ `ResizeObserver`（缩放/布局）→ rAF 节流
  → `mpv_player_set_rect`。**没有消息 Hook**（见下踩坑 ①）。
- **控件**：VideoControls `mpvMode` 轮询（250ms）驱动进度/时长/音量显示；
  播放/暂停/±5s/逐帧（`frame-step`，不依赖 fps 元数据）/音量/静音/循环可用；
  键位全套（空格/k、j/l、←→、, .、0-9、Home/End、↑↓、m）+ 滚轮音量已分派。
- **删除**：ImageViewer 的 remux 兜底阶梯全链（remuxOutput/Pending/Progress/Failure/
  forceRemuxTriedRef/onRemuxProgress 订阅/进度卡）；`mpvPocBridge.ts`。

### 踩坑记录（S1 实测，S2 前必读）

1. **`SetWindowSubclass` 方案否决**：comctl32 v6 函数（`SetWindowSubclass`/
   `TaskDialogIndirect`，tao/tauri 自身导入）需要 manifest 声明 Common-Controls v6；
   test harness exe 没有 → `STATUS_ENTRYPOINT_NOT_FOUND (0xc0000139)`。
   **跑测试必须 `AURORA_TEST_MANIFEST=1 cargo test --lib`**（build.rs 已备开关）。
   同理 `GetDpiForWindow`（Win10+ user32）也勿在会进测试 exe 的代码里静态导入
   —— DPI 换算放前端 `devicePixelRatio`（口径更准）。
2. **`SetWindowLongPtrW` 手动链 wndproc 否决**：跨线程窗口操作风险
   （open 跑在 invoke worker 线程）。
3. **popup 复用 ctx 换片否决**：open 的 load_and_wait（最长 5s）与 stop 并发
   → UAF；持锁又会让 rect 同步阻塞。当前语义 = 每次新建窗口、成功后替换
   （切文件黑闪 ~百毫秒，S2 可评估优化）。
4. **popup 建在 invoke 线程（无消息循环）** ⇒ popup 的鼠标消息（点击暂停）
   收不到 —— 点击暂停 S1 不存在，键盘路径全覆盖。S2 若要点击暂停：
   popup 窗口挪到专用消息泵线程，或 mpv 侧 input 处理。
5. **popup 覆盖区内 HTML 全部不可见**：加载失败必须先 `stop()` 再显示错误卡
   （已实现：`mpvError` 卡只在 popup 未建立时可见）；全屏（chromeOverlay）下
   控制条会被 popup 盖住 —— **S2 待办**（方案候选：mpv 模式禁用 chromeOverlay
   浮层改独立条布局；或第二层工具条 popup）。
6. **flaky 测试**：`client_async_flow_goes_pending_then_ready_by_polling` /
   `remux_real_samples_when_ffmpeg_present` 偶发红（真实 ffmpeg + 共享缓存目录
   时序），重跑即绿，与 S1 无关（S1 未动 video_remux）。

## §6 全局约定

1. **判定看编码，不看容器**（不同容器装同编码，结论不同）
2. **桌面端画面窗口必须 top-level popup**（`WS_CHILD` 必被 WebView2 覆盖，与 z-order 无关）
