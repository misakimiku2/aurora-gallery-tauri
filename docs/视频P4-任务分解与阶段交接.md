## §2 目标架构（最终态）

```
桌面端本地播放
  ├─ Chromium 能解的编码（H.264/VP8/VP9/AV1…）→ WebView2 <video>（现状保留）
  └─ 其余一律 → libmpv 嵌入（popup 顶层窗口，跟随主窗口同步）  ← 播原文件，零转码

LAN 手机端播放
  ├─ 手机能解的容器 + 编码 → HTTP Range 直读原文件（现状 direct）
  └─ 其余 → 服务端 HLS 流式（EVENT 分片，不落全量、秒开、原生 seek）
```

**两条腿互不依赖**，可并行推进。

**最终收益**：
- 桌面端：`video_remux` 桌面端路径（remux 作业 / LRU / 4 GiB 预算 / 等待态 UI）**整体删除**
- LAN 端：从「等 102 秒」变成「约 1 秒起播」

  forceRemuxTriedRef/onRemuxProgress 订阅/进度卡）；`mpvPocBridge.ts`。

### 踩坑记录（S1 实测，S2 前必读）

1. **`SetWindowSubclass` 方案否决**：comctl32 v6 函数（`SetWindowSubclass`/
   `TaskDialogIndirect`，tao/tauri 自身导入）需要 manifest 声明 Common-Controls v6；
   test harness exe 没有 → `STATUS_ENTRYPOINT_NOT_FOUND (0xc0000139)`。
   **跑测试必须 `AURORA_TEST_MANIFEST=1 cargo test --lib`**（build.rs 已备开关）。
   同理 `GetDpiForWindow`（Win10+ user32）也勿在会进测试 exe 的代码里静态导入
   —— DPI 换算放前端 `devicePixelRatio`（口径更准）。
2. **`SetWindowLongPtrW` 手动链 wndproc 否决**：跨线程窗口操作风险
   （open 跑在 invoke worker 线程）。
3. **popup 复用 ctx 换片否决**：open 的 load_and_wait（最长 5s）与 stop 并发
   → UAF；持锁又会让 rect 同步阻塞。当前语义 = 每次新建窗口、成功后替换
   （切文件黑闪 ~百毫秒，S2 可评估优化）。
4. **popup 建在 invoke 线程（无消息循环）** ⇒ popup 的鼠标消息（点击暂停）
   收不到 —— 点击暂停 S1 不存在，键盘路径全覆盖。S2 若要点击暂停：
   popup 窗口挪到专用消息泵线程，或 mpv 侧 input 处理。
5. **popup 覆盖区内 HTML 全部不可见**：加载失败必须先 `stop()` 再显示错误卡
   （已实现：`mpvError` 卡只在 popup 未建立时可见）；全屏（chromeOverlay）下
   控制条会被 popup 盖住 —— **S2 待办**（方案候选：mpv 模式禁用 chromeOverlay
   浮层改独立条布局；或第二层工具条 popup）。
6. **flaky 测试**：`client_async_flow_goes_pending_then_ready_by_polling` /
   `remux_real_samples_when_ffmpeg_present` 偶发红（真实 ffmpeg + 共享缓存目录
   时序），重跑即绿，与 S1 无关（S1 未动 video_remux）。
7. **StrictMode 双挂载竞态（2026-10-20 真机抓出，已修）**：dev 模式 effect 走
   挂载→卸载→再挂载，第一次卸载的 `mpvStop` 晚于第二次 `mpvOpen` 到达 →
   **误杀新会话的播放器**（症状：一帧画面后消失 + 控制条操作报「尚未挂接 mpv」）。
   修法 = **session 令牌贯穿 open/stop**：前端 effect 里同步 `nextMpvSession()`，
   Rust 只销毁完全匹配自己会话的 surface；晚到的 open 完成时发现已有更新会话
   → 自杀让位（`LATEST_SESSION`）。同时播放类命令（seek/pause/volume…）在前端
   吞错——surface 消失的竞态窗口里操作本就无意义，抛出去只是 uncaught promise
   噪音，状态由轮询自愈。

## §4.6 S2 落地记录（2026-10-20，`840b7f0fa`）—— 交给 S3 的现场

### 已落地

1. **视频背景主题色（指挥官点名）**：letterbox 区不再是全黑 —— 前端 `getMediaBackground`
   （getComputedStyle 实时取媒体区背景）→ open 初始化选项 + `set_rect` 运行时
   `background-color` 双通道；主题切换（html.dark）由 MutationObserver 触发推送。
   亮色=白、暗色=#262626、沉浸/幻灯片/全屏=黑，全部自动正确。
2. **点击画面 = 播放/暂停、滚轮 = 音量**：popup 建在 invoke 线程无消息循环，
   WndProc 收不到鼠标 —— 用 **WH_MOUSE_LL 低级鼠标钩子**（回调投到主线程，
   主线程装/卸 via `run_on_main_thread`；几何判断命中 popup rect 才
   emit `mpv://surface {kind, delta}`）。回调只做 PtInRect + emit，微秒级。
3. **全屏修正**：mpv 模式禁用 chromeOverlay 浮层（`chromeOverlay = ... && !shouldUseMpv`）
   —— 浮层画在 WebView 内会被 popup 盖住；控制条保持独立条，媒体区 rect 自动跟随。
   mpv 全屏时媒体区黑底（与原全屏行为一致）。
4. **倍速**：mpv `speed` 属性 —— 控制条按钮（0.5/1/1.25/1.5/2 循环，即时反馈 +
   轮询回读确认）+ `<`/`>` 键 ±0.25（state 缓存取当前值）。

#### S5-A · libmpv 下载器设计要点（动手前读）

**决策**：`libmpv-2.dll`（~120MB）**不打包进安装包**，改为运行时按需下载
——安装包体积不会因播放内核膨胀，也天然符合 LGPL「可替换」形态。

**仿 `ffmpeg_download.rs` 的成熟范式**（照抄结构，别重新发明）：
- **来源**：shinchiro 的 mpv-winbuild **LGPL** 构建（SourceForge/GitHub releases），
  只取包内 `libmpv-2.dll`；**pin 死版本 tag + 校验 SHA256**（清单写死在代码里），
  另留「latest」档仅作提示（与 ffmpeg 的 pinned/latest 双档 + 未校验来源警示同款）。
- **落点**：`%LOCALAPPDATA%\com.aurora.gallery\mpv\libmpv-2.dll`
  （与 ffmpeg 同目录组织，`mpv_player.rs::load_lib` 已按此路径加载，无需改动）。
- **下载体验**：120MB → 必须有进度事件（复用 ffmpeg 的 `DownloadProgress` 机制）、
  断点/失败重试、`.part` 半成品与 sha 校验后改名（**别写坏已装好的 dll**：
  先写 `libmpv-2.dll.part`，校验通过再原子替换）。
- **UI 入口**（两处，缺一不可）：
  1. 设置面板组件卡片（仿「视频封面引擎」ffmpeg 卡片）：状态 = 未安装 /
     安装中+进度 / 已安装+版本 / 更新可用；按钮 = 安装 / 更新 / 重新安装。
  2. **播放路径引导**：`mpvFailed` 错误卡（文案已含「缺少 libmpv 组件」）加
     「安装播放内核」按钮直达该设置卡片——用户第一次点开 avi 时的唯一自然入口。
- **合规**：LGPL 2.1 动态链接 ⇒ ① 不阻止用户替换 dll（固定路径读取即满足；
  版本号读 `mpv-version` 属性，替换后版本变化照常工作）② `licenses/` 登记 +
  随包提供源码获取方式 ③ 下载器不校验用户替换的文件（只在安装时校验下载包）。
- **测试**：删掉 dll → 点开 avi → 应走错误卡引导 → 下载 → 直接可播（端到端验收）。

## §6 全局约定

1. **判定看编码，不看容器**（不同容器装同编码，结论不同）
2. **桌面端画面窗口必须 top-level popup**（`WS_CHILD` 必被 WebView2 覆盖，与 z-order 无关）
3. **运行时加载 dll，不链接导入库**（LGPL 合规 + msvc/MinGW 格式不匹配）
4. **本机跑 cargo 必须清代理环境变量**：
   `http_proxy= https_proxy= HTTP_PROXY= HTTPS_PROXY= cargo <cmd>`
   （端口会变，历史记录 7897 已过时，当前环境变量是 8819 且返回 502）
5. **改完 src-tauri 核心跑 `cargo test --lib` 收口**，别只跑 `cargo check`
