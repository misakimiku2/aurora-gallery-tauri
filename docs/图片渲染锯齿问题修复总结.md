# 图片渲染锯齿问题修复总结

## 问题描述

在 Aurora Gallery 应用中，多处图片渲染存在锯齿问题：

1. **专题封面**：自动设置的专题封面（无裁剪数据时）显示有锯齿
2. **人物头像**：无 `faceBox` 数据的人物头像显示有锯齿
3. **详情面板封面**：MetadataPanel 中的专题封面使用背景图片方式渲染，存在锯齿

## 问题原因分析

### 渲染方式差异

| 场景 | 有裁剪数据 | 无裁剪数据 |
|------|-----------|-----------|
| 专题封面 | 使用绝对定位精确显示裁剪区域 | 使用 `object-fit: cover` 自动缩放 |
| 人物头像 | 使用 `faceBox` 数据精确显示人脸区域 | 使用 `object-fit: cover` 自动缩放 |

### 锯齿产生原因

`object-fit: cover` 会让浏览器对图片进行缩放处理，可能导致：
- 图片被缩放到非原始尺寸
- 浏览器的缩放算法产生锯齿
- 特别是对于高分辨率图片，缩放后显示效果较差

而使用绝对定位方式（有裁剪数据时）是直接显示原图的一部分，不涉及缩放，因此没有锯齿。

## 解决方案

### 核心思路

**统一渲染方式**：无论是否有裁剪数据，都使用绝对定位方式渲染图片。

1. **有裁剪数据时**：直接使用裁剪数据进行绝对定位渲染
2. **无裁剪数据时**：
   - 图片加载后获取原始尺寸
   - 自动计算居中的裁剪区域
   - 使用绝对定位方式渲染

### 实现细节

#### 1. TopicCoverImage 组件 (TopicModule.tsx)

```typescript
const TopicCoverImage = React.memo(({ topic, className }: { topic: Topic; className?: string }) => {
    const coverUrl = getCoverUrl(topic);
    const [imgDimensions, setImgDimensions] = React.useState<{ width: number; height: number } | null>(null);
    
    const handleImageLoad = React.useCallback((e: React.SyntheticEvent<HTMLImageElement>) => {
        const img = e.currentTarget;
        setImgDimensions({ width: img.naturalWidth, height: img.naturalHeight });
    }, []);

    if (!coverUrl) return null;

    const crop = topic.coverCrop;
    const hasValidCrop = crop && crop.width > 0 && crop.height > 0;

    let renderCrop: { x: number; y: number; width: number; height: number } | null = null;

    if (hasValidCrop) {
        renderCrop = crop;
    } else if (imgDimensions) {
        // 自动计算 3:4 比例的居中裁剪区域
        const { width: imgW, height: imgH } = imgDimensions;
        const targetAspect = 3 / 4;
        const imgAspect = imgW / imgH;

        if (imgAspect > targetAspect) {
            // 图片更宽，裁剪左右
            cropH = 100;
            cropW = (targetAspect / imgAspect) * 100;
            cropX = (100 - cropW) / 2;
            cropY = 0;
        } else {
            // 图片更高，裁剪上下
            cropW = 100;
            cropH = (imgAspect / targetAspect) * 100;
            cropX = 0;
            cropY = (100 - cropH) / 2;
        }

        renderCrop = { x: cropX, y: cropY, width: cropW, height: cropH };
    }

    // 使用绝对定位方式渲染
    return (
        <div className={`overflow-hidden relative ${className || ''}`}>
            <img
                src={coverUrl}
                alt={topic.name}
                className="absolute"
                decoding="async"
                onLoad={!hasValidCrop ? handleImageLoad : undefined}
                style={{
                    width: `${10000 / safeWidth}%`,
                    height: `${10000 / safeHeight}%`,
                    maxWidth: 'none',
                    minWidth: 'unset',
                    left: `${-renderCrop.x / safeWidth * 100}%`,
                    top: `${-renderCrop.y / safeHeight * 100}%`,
                    imageRendering: 'auto'
                }}
            />
        </div>
    );
});
```

## 渲染公式说明

### 绝对定位裁剪渲染

使用 CSS 绝对定位来实现图片裁剪显示：

```css
/* 容器 */
.container {
    overflow: hidden;
    position: relative;
}

/* 图片 */
.image {
    position: absolute;
    /* 关键公式 */
    width: 10000 / cropWidth %;
    height: 10000 / cropHeight %;
    left: -cropX / cropWidth * 100 %;
    top: -cropY / cropHeight * 100 %;
}
```

### 公式解释

- `cropWidth`, `cropHeight`: 裁剪区域的宽高百分比（0-100）
- `cropX`, `cropY`: 裁剪区域左上角的坐标百分比（0-100）
- 图片被放大到足够大，然后通过负的 left/top 偏移来显示正确的裁剪区域

### 裁剪区域计算

#### 专题封面（3:4 比例）


## 注意事项

1. **React Hooks 规则**：`useState` 和 `useCallback` 必须在所有条件返回之前调用
2. **图片加载时机**：只有在无裁剪数据时才需要监听 `onLoad` 事件获取图片尺寸
3. **性能优化**：使用 `React.memo` 包装组件，避免不必要的重渲染
4. **数值安全**：裁剪宽高需要限制在合理范围内（0.1-99.9），避免除零错误

## 效果

修复后，所有图片渲染都使用统一的绝对定位方式，无论是否有裁剪数据，都能获得清晰无锯齿的显示效果。
