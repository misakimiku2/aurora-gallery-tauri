## 2. 架构（已定，改动前必读）

```
<视口 overflow:hidden>                       ← 平移缩放、滚轮/空格抓手
  └ <画布容器 w=canvas.w h=canvas.h overflow:hidden 背景=棋盘格|白|黑>
      └ <图层 img src=原文件(convertFileSrc) transform=matrix(a,b,c,d,e,f)>
```

| 事实 | 说明 |
|---|---|
| **文档 = 画布 + 图层** | `canvas{width,height,background}` + `layers[]`；`LayerBox{x,y,w,h,rotation,flipH,flipV,skewX,skewY}` |
| **`w/h` 是未旋转的内容尺寸** | 旋转由 `rotation` 单独表达。**交换 w/h 会让内容被拉伸**（踩过一次） |
| **两端共用一组六参** | `composeMatrix(box, natural)` → CSS `matrix()` / Rust `AffineMatrix`，两边都不再自行推导 |
| **显示走原文件** | 放大到 100% 看到真像素；Rust 代理图只服务缩略图（与将来的超大图打底） |
| **裁剪非破坏性** | 改画布尺寸 + 图层反向平移，像素不删；导出按画布裁切 |
| **画布旋转是"一次性换算"** | `rotateDocumentCanvas` 只映射中心、角度 ±90，不留文档级 rotation 字段 |
| **调色是图层属性** | 预览 CSS `feColorMatrix`，导出 Rust 同一矩阵；`adjust` 不进代理图缓存键 |
| **EXIF 方向折进变换** | core 手写解析 tag 0x0112 → `orientationToBox` → 图层 img 设 `imageOrientation:'none'` |
| **撤销只存参数** | `{canvas, layers}` 快照；`documentStateSignature` 判变（**含图层 id**），700ms 内纯调色合并成一步 |
| **面板缩略图按层按需生成** | `layerProxy.ensureLayerPreview`：并发闸 2、按路径去重、失败不重试；代理缓存上限 16 |
| **工程 = 自包含 ZIP** | `.aurora` 里 `images/<md5>.<ext>` 存源文件**原字节**（v2 图层从不烘焙像素，原字节即无损，顺带保住 EXIF 方向）；同一份内容只存一次 |
| **读工程 = 解压到临时目录** | 图层仍以**文件路径**交给画布（`convertFileSrc`），不走 blob/data URL；解压目录按内容寻址，重开不重写 |
| **蒙版 = 独立图片乘 alpha** | 每层可选 `mask`（对象：source + 自然尺寸 + 可选独立框）。蒙版值 = 亮度 × 蒙版自身 alpha（CSS luminance 模式同款），**缺独立框 = 链接**（拉伸铺满整层、跟图层同变换）；**有独立框 = 解链**（蒙版自己的画布空间矩阵）。预览 CSS 壳嵌套（A 蒙版壳 + B 内容壳，坐标换算 `inv(Q)·M`）、导出 Rust `apply_mask`（解链时把蒙版 warp 到图层内容空间 `inv(M_layer)·M_mask`，与 CSS 数学同构）、工程里与图层图共用 `images/` 的 md5 去重 |
| **剪贴蒙版 = 基础层 alpha 裁上层** | 每层可选 `clipped`：只显示在**同分段内下方最近的基础层**（非剪贴层）有像素处；连续剪贴层链式裁进同一个基础层。预览 = 与基础层同矩阵的壳 + `mask-image`（**alpha 模式**，与图层蒙版的 luminance 相区分）；导出 = Rust 把剪贴层 warp 到 scratch、alpha 乘基础层 warp 光栅再叠回（层的 blend/opacity 保留）。**不跨组**（组行不参与）；数据损坏（找不到基础层）按普通层渲染，两端同口径 |

|---|---|

| 眼睛 | 切换 `visible`。画布用 `opacity:0`，**导出必须过滤**（Rust 侧不知道可见性，见 §6 第 5 条） |
| 复制 / 删除 | 两个纯图标按钮在**面板底部右侧**（PS 同款，2026-10-24；顶部只留锁）。复制插在原层上方、名加「 副本」；删除也可以直接按 **`Delete`** 键（裁剪/自由变换时不抢这个键，输入框里也不抢）。**删除是蒙版优先**（用户口径 2026-10-24 第二轮反馈：不搞分离按钮）：活动层带蒙版时，删除（按钮或 Delete）**先删蒙版**、选中对象回图层本体，再按一次才删图层——面板不再有单独的「删蒙版」按钮。组行照旧删组连带成员。删掉活动层时活动层落到**它下面那层**，删空则无活动层（**不会**把图重建回来，见 §6 第 6 条） |
| 不透明度 | 每行**右侧的百分比**：点一下开弹窗，弹窗里**只有一条滑杆 + 右侧百分比数字**（无标签、无说明文字、数字不带上下微调按钮）；点数字变输入框，Enter/blur 提交、Esc 取消。**按住行内数字左右拖 = 快速擦调**（2px = 1%）。预览走 CSS、导出走 alpha 缩放，两端同一个百分比 |
| 编组 | 操作条上的**编组/取消编组**按钮 + 组行（可折叠的文件夹行，成员缩进）。**已用户实测验收（2026-10-24）**。数据 = 扁平 + 连续段（成员 `groupId` 指向组行，数组序连续）。**合成语义**：组内先互相合成 → 组画布按**组的**不透明度/混合模式整体叠到底板（Rust `composite_grouped` 分段合成；CSS 用嵌套 div，两端同构，分段共用 `splitSegments`）。组行自身的眼睛/不透明度/混合模式/改名/锁定全可用（作用于组）；删除组 = 连带成员（面板与 Delete 键同口径）；组结构进撤销签名、落 `.aurora`（`layerKind`/`groupId`，老工程按平层读）。**组行缩略图无底板**（只显示折叠箭头+文件夹图标，2026-10-24 用户要求去矩形背景；选中态交给整行高亮，不画白圈）。v1 待办：拖拽跨组进出、自动选择「组」档、嵌套组 |
| 蒙版 | **v1 + 第二轮交互均已落地（2026-10-24）**：每层可选 `mask`（source + 自然尺寸 + 可选独立框）。**面板**：底部左侧「添加/更换蒙版」（文件对话框选图；**没有单独的删蒙版按钮**——删除走右下角那个，蒙版优先，见「复制/删除」行）；行内**图层缩略图 + 链条 + 蒙版缩略图**（无蒙版时后两者不占位）。**点缩略图切换选中对象**（target = 图层/蒙版，PS 同款白边选中框；选区不进签名、不落工程）：target=蒙版时拖动/Ctrl+T 改蒙版的框（解链态）；**Delete 不再看 target，一律蒙版优先**（有蒙版先删蒙版）。**链条**：链接→解链给蒙版一份图层框拷贝起步（之后独立移动/变换）；解链→链接删独立框（蒙版回到跟图层走）。**链条不是"蒙版开关"**（PS 同款：蒙版永远生效，链条只控制变换联动）——解链瞬间画面不变是刻意设计（拷贝起步），解链态链条图标**蓝色高亮** + tooltip 写明验证方法（解链后拖图层→蒙版留在原地）。**停用/启用蒙版**（`mask.disabled`，PS 的 Shift+点缩略图，2026-10-24 用户确认后加）：停用 = 蒙版**暂时不参与合成**（预览按无蒙版渲染、导出载荷 mask 发 null——Rust 无需新路径），数据原地保留、缩略图打红叉，再 Shift+点恢复；**链条来回（解链/再链接）不丢停用标志**；进两个签名（离散撤销步）、落 `.aurora`（`maskDisabled`，老工程缺字段按启用读）。**合成**：链接态拉伸铺满；解链态带自己的矩阵。**壳几何在 `layerTransform.maskShellSpec`（纯函数、有单测）**：链接 = 壳取**图层**自然尺寸 + 图层矩阵、蒙版靠 `mask-size:100%` 拉伸（≠ 蒙版自然尺寸，§6 第 22 条），解链 = 蒙版自然尺寸 + 自己的矩阵；预览 CSS 壳嵌套（A=luminance 蒙版壳、B=内容壳）、导出 Rust `apply_mask`（解链 warp 到内容空间走同一乘法）；顺序 = 调色 → 不透明度 → 蒙版 → 重采样。**进两个签名**；删字段保持文档干净。**工程**：`maskFileName` + `maskBox` 落 layout、`images/` md5 去重、打开回传蒙版自然尺寸；蒙版解压失败**不弃层**。逻辑在 `useEditorMask`/`layerModel`，载荷在 `buildRenderGroups`。**边界**：蒙版上作画等画笔、组行不支持、EXIF 方向 JPEG 蒙版两端有差异（灰度 PNG 是预期形态） |
| 剪贴蒙版 | **已落地（2026-10-24 第二轮，PS 的 Clipping Mask）**：`clipped` 的层只显示在**同分段内下方基础层**有像素处（吃基础层 alpha，与图层蒙版的黑白语义无关）。**入口**：面板 **Alt+点行** 切换（PS 是 Alt+点分割线，放宽到整行）+ **Ctrl+Alt+G**（活动层）；被剪贴的行左侧折线箭头 + 轻微缩进；**按住 Alt 悬停时，可剪贴/已剪贴的行换 `alias` 光标**（功能唯一可见提示，用户 2026-10-24 反馈"光标还是手指看不出有这功能"后加；blur 兜底防 Alt+Tab 卡住）。**判定**：`layerClipping.ts`（`canClipLayer`/`findClipBase`，分段口径与 `splitSegments` 一致、不跨组）；连续剪贴层链式裁进同一基础层。**合成**：CSS = 与基础层同矩阵的壳 + 基础层图做 **alpha** 蒙版（子层矩阵换算 `inv(M_base)·M_child`）；Rust = scratch warp × 基础层 warp 光栅 alpha。**进两个签名**、落 `.aurora`（`clipped`）。**已知近似**：壳因 transform 自成 stacking context，剪贴层挂**非 normal 混合模式**时 CSS 预览只与壳内合成（Rust 导出精确，normal 模式两端一致）；基础层带自身图层蒙版/半透明时 CSS 用原图 alpha、Rust 用合成后 alpha——极端组合下预览与导出有细微差，记录在案。**使用注意**：基础层若铺满画布且处处不透明（如整张截图），裁进它**视觉上等于没裁**（处处有像素）——想看出效果要拿带透明区域的层当基础层 |
| 锁定 | 面板顶部**四格开关**（PS 同款，作用选中层；复制/删除已移到底部右侧）：锁透明像素（**灰显**，等画笔/填充）、锁像素（禁变换）、锁位置（禁移动+变换）、锁全部（像素+位置联动）。生效点：锁位置 = 画布拖不动（EditOverlay `isEditMode`）；锁像素/锁位置 = Ctrl+T 拒进 + 变换态自动弹回移动工具。**其余操作不受影响**（删除/重排/眼睛/改名/不透明度/混合模式/调色，PS 口径）；锁开关**不进撤销栈**；落 `.aurora`（serde default false 兼容老工程）；锁定层行上显示小锁 |
| 混合模式 | **下拉在面板顶部、作用于活动图层**（2026-10-24 用户要求从每行移上来，PS 同款位置；行内只留不透明度数值）：**悬停下拉框直接滚轮换档（不点开）**，点开弹窗后弹窗内也可滚轮连续试档（都是循环 wrap、即时提交）；12 档可分离模式，名字与 CSS `mix-blend-mode` **同名同一套字符串**——预览交 CSS（`mixBlendMode`）、导出交 Rust（`BlendMode::parse`），两端不翻译。`normal` 不落字段；未知值两端都落 `normal`（`normalizeBlendMode` / `parse` 同口径，有单测锁）。 PS 的非可分离档（色相/饱和度/颜色/明度）这轮不做 |
| 全览图 | **整份文档的合成**（PS 的 Navigator 语义，2026-10-24 前只显示活动图层那一层）：走 `editor_render_document`（与导出同一条路，含调色/不透明度/蒙版、跳过隐藏层与被关掉的组），文档图层一变防抖 300ms 重渲。载荷与导出**共用 `buildRenderGroups`**（2026-10-24 修：编组落地后这里一度还在发旧的 `layers` 平铺形状，Rust 缺 `groups` 反序列化失败、错误又被 catch 吞掉——全览静默失效）。依赖用 `layers` 的**引用**（换选区不重渲）。RightPanel 的 `editorMeta` 订阅随之拆掉。**只压暗视口框以外**（四条矩形拼出框外的上/下/左/右，框内原样）——它是位置参照，不该跟主画布抢亮度。**视口盖住整份文档（缩小到适应窗口）时什么都不压暗**：此时没有框外区域，旧逻辑把它当成"没有框"退回整块压暗，就是"缩小后全览图全暗"那个 bug（2026-10-24 修） |

## 6. 踩过的坑（改这块之前先看这几条）

1. **StrictMode 双跑**：`main.tsx` 开着 StrictMode，任何"只跑一次"的 effect 都必须在清理时复位自己的 ref，且 `cancelled` 不能连带吞掉错误分支——否则表现为"卡在正在打开…"且看不到报错。
2. **`w/h` 不能交换**：定界框里它是未旋转的内容尺寸；v1 的 `rotateCropRect` 交换 w/h 是**轴对齐矩形**语义，照搬会让画面拉伸。
3. **命中判定不能用包围盒**：45° 旋转时包围盒四角是空的，必须 `pointInBox`（反旋到本地坐标）。
4. **EditOverlay 有三个独立开关**：`isEditMode`（能否拖动）/ `showTransformHandles`（手柄与旋转区）/ `showChrome`（蓝框）。共用一个会连坐——移动工具曾因此完全拖不动。
5. **`editor_load_layer_proxy` 的尺寸是存储方向**：浏览器 `<img>.naturalWidth` 是**转正后**的，用它建画布会和导出错位。
6. **改了 Rust 必须完全重启**：`tauri:dev` 是 `--no-watch`，`Ctrl+R` 只刷前端。
7. **脚本改文件要保行尾**：Python `io.open(..., encoding='utf-8')` 默认把 CRLF 读成 LF 再写回，会制造整文件假改动。
8. **JSON 键名是跨语言契约**：`box` 是 Rust 保留字，两端的结构体都用 `#[serde(rename = "box")]` 把它挂到 `frame` 字段上。漏一个 rename 的表现是"打开工程后所有图层挤在左上角、尺寸 0×0"——不报错、只是画错了。`json_keys_match_frontend_contract` 那条单测就是盯这个。
9. **`doc.path` 不能进 `docIdentity`**：保存会把路径从 `photo.jpg` 换成 `photo.aurora`，身份一变撤销栈当场清空（"刚存完就撤不回去了"）。文档身份只看"画布是否就绪"。
10. **`.aurora` 不是图片**：`needsInit` 的判据必须排除工程路径，否则把**空白文档**存成工程后，`path` 一变就会去解码一个 ZIP（表现为画布上盖一层"无法打开这张图"）。
11. **不可见的图层 Rust 照样合成**：`DocumentRequest` 里根本没有 `visible` 字段，`composite` 只按数组逐层画。所以"关掉眼睛"必须在**前端** `handleExport` 的 filter 里剪掉，否则屏幕上没有、导出里又有（2026-10-24 加可见性开关时一并修）。
12. **`needsInit` 的 `layerCount === 0` 不等于"还没初始化"**：用户把最后一层删掉也会得到 0，初始化 effect 会当场把那层从源文件重建回来（表现为"删不掉最后一层"）。判据要另加一个"已成功初始化过这个路径"的 ref（`initDoneRef`）。注意它**不能**在 effect 清理时复位——复位就退化成 `initStartedRef`。
13. **签名必须含图层 `id`**：两张同源同尺寸的图层（复制出来的）在其余字段上一模一样，只有 id 能区分。漏了的表现是"把副本挪一层"不进撤销栈（这条是单测抓的，不是人肉发现）。
14. **不透明度 = 合成前的 alpha 缩放**，不是"给 `composite` 加参数"：混合是直通 alpha 的 src-over，整层半透明等价于每像素 alpha 乘同一系数。在 `composite` 里乘会**连重采样插值出来的 alpha 也再乘一遍**，边缘发暗。顺序定在「调色之后、重采样之前」。
15. **两个签名各收什么，是刻意的分工**：`layerStateSignature`（撤销"变了没"）要含 `adjust` 与 `opacity`；`layerGeometrySignature`（判断"是不是只在拖滑杆"）**不能**含它们，否则拖一次滑杆灌上百条历史。加新字段时先想清楚它属于哪一类。
16. **同一个控件既要"点一下"又要"按住拖"时，两种手势会打架**：行内不透明度用 Pointer Events + `setPointerCapture`（拖动中途指针移出那个 9 个字宽的小方块也不会断），3px 阈值区分"手抖"与"拖动"；同时这些元素必须打 `data-no-drag`，让父级 HTML5 `onDragStart` 用 `closest()` 把它们挡掉——否则"按住数值左右拖"会变成"拖整行排序"。
17. **带 `transform`/`willChange` 的祖先会吃掉 `position: fixed`**：右面板容器为了滑入动画带 `transform` + `willChange: 'transform'`，外层还有 `overflow-hidden`——面板里任何 fixed 定位的浮层都会**以它为定位基准并被裁掉**（表现为"点了没弹窗"）。面板里的浮层一律 `createPortal` 到 `document.body`。
18. **图层面板的两个"顺序"**：文档里 `layers` 是**自底向上**（下标 0 最先画），面板必须**自顶向下**。反转只在 `layersTopDown` 做一次；谁在别处又 reverse 一次，"上移"就会变成"下移"。
19. **混合模式的名字是两端共用的一份字符串**：取值就是 CSS `mix-blend-mode` 的名字（kebab-case），预览 `mixBlendMode` 直接吃、导出 `BlendMode::parse` 直接吃。任何一边改名（或加档）必须 `blendModes.ts` 的表、Rust 枚举、两份单测**四处同步**。两个硬点：①预览的混合组必须 `isolation: isolate`，白/黑底画在**组内**（参与混合，与 Rust 先铺背景再叠层一致）、棋盘格留在组外——否则最底下那层会跟画布外的应用背景混；②公式在**非预乘空间**做，`blend_over` 对 backdrop α=0 必须**直通源**（有单测 `blend_degenerates_to_source_when_backdrop_is_transparent` 盯着，防有人在预乘空间直混把半透明层压成 0）。回 `normal` 时删字段（与不透明度回 100 同一口径）。
20. **IPC 载荷的键名是 camelCase，snake_case 会被 serde 静默丢掉**（2026-10-24 蒙版动工时抓到的存量 bug）：`editor_commands.rs` 的 `ProjectLayerRequest` 等结构整体挂 `#[serde(rename_all = "camelCase")]`，前端 `buildSavePayload` 却发过 `lock_pixel` / `layer_kind` / `group_id`——serde 对未知键不报错、缺字段走 default，**锁定与编组存盘后再打开无声丢失**。core 层的往返单测直接构造 `SaveLayer`、不穿 IPC，所以一直是绿的。对策：①前端 `projectFile.ts` 全 camelCase（有单测钉死键名集合）；②`editor_commands.rs` 尾部有 IPC 契约测试，把前端实际发出的 JSON 形状钉在 Rust 侧。**新加任何跨 IPC 字段，两边键名必须一起过这两个测试**。
21. **吞掉错误的 catch 会把功能变成"静默失效"**：全览图在编组重构后还在发旧的 `layers` 平铺形状，Rust 缺 `groups` 反序列化失败，而前端 `.catch(() => {})` 把它吞了——面板从此一直显示占位图，没有任何报错。教训：①"预览失败不打扰用户"的 catch 也要留一行 console；②**导出与全览这类同构请求必须共用同一份构造函数**（`buildRenderGroups`），各写一份迟早漂移；③同批还抓到"组行被眼睛关掉但导出仍带组员"——旧的内联导出构造从没判过 `row.visible`，也是同构漂移的产物。
22. **链接态蒙版壳必须按图层（不是蒙版）的自然尺寸建**（2026-10-24 第二轮重构踩的坑，用户实测"链接蒙版几乎全透明、解链反而正常"抓到）：壳上的 `transform` 是**图层**矩阵，它把"图层内容坐标"映射到画布——壳若按**蒙版**自然尺寸建，就只盖住图层内容的一角，`mask-repeat: no-repeat` 之外全按隐藏处理。正确做法：链接 = 壳取图层自然尺寸 + 图层矩阵、蒙版靠 `mask-size: 100% 100%` 拉伸铺满（等价于"mask 直接挂 img"）；解链 = 蒙版自然尺寸 + 自己的矩阵。壳几何抽成了 `layerTransform.maskShellSpec` 纯函数，四角重合关系有单测钉着——**导出（Rust 拉伸路径）从头就是对的，这类"只有预览错"的 bug 优先怀疑壳几何**。

## 7. ImageEditor 防膨胀规则（2026-10-24 立，动工前先看）

现状：`ImageEditor.tsx` 已 1664 行（editor 目录共 ~5900 行）。它**不该**继续长——每加一个
功能块就按下面的边界搬一次，保持它是个**薄编排层**（目标 <500 行）：

1. **纯逻辑 → hook 文件**：键盘快捷键 → `useEditorKeyboard`；滚轮/空格/缩放平移 →
   `useEditorViewport`；裁剪状态机 → `useEditorCrop`；撤销栈 → `useEditorHistory`。
   hook 收状态依赖，返回 handler，ImageEditor 只留一行调用。
2. **成块的 UI → 组件文件**：一段 JSX 有自己的状态或超过 ~50 行就拆（画布渲染段 →
   `EditorCanvasLayers`）。
3. **两端共用的数学/名字表 → 独立 ts 模块**：照 `cropGeometry` / `colorMatrix` /
   `blendModes` 的模式。
4. **搬家的时机 = 顺手**：做完一个功能就把相关逻辑搬走，**不做攒到一起的大重构**
   （搬完 `wc -l` 看 ImageEditor 行数，涨了就说明这轮没搬干净）。
5. 拆分批次：**A-E 全部完成（2026-10-24）**——`useEditorKeyboard`（201 行）/
   `useEditorViewport`（230）/ `useEditorCrop`（92）/ `useEditorHistory`（101）/
   `EditorCanvasLayers`（124），ImageEditor 1664 → 1106 行。蒙版两轮（同日）照规则落位：
   流程进 `useEditorMask`、载荷进 `renderPayload`（导出/全览共用）、剪贴判定进
   `layerClipping`（50）、壳渲染结构进 `EditorCanvasLayers`（378）。ImageEditor
   第二轮 1105 → **1140 行**（+35 = 蒙版 target 的框分流 `patchTargetBox`，属编排
   本职）；EditorPanel 1299 → **1394**（+95 = 行内缩略图/链条/剪贴 UI，全在本行
   组件里）。剩余大头不变：初始化 effect、导入/工程 handler、文档栏 JSX
