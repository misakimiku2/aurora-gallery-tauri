## 1. 一句话状态

## 2. 架构（已定，改动前必读）

```
<视口 overflow:hidden>                       ← 平移缩放、滚轮/空格抓手
  └ <画布容器 w=canvas.w h=canvas.h overflow:hidden 背景=棋盘格|白|黑>
      └ <图层 img src=原文件(convertFileSrc) transform=matrix(a,b,c,d,e,f)>
```

| 事实 | 说明 |
|---|---|
| **文档 = 画布 + 图层** | `canvas{width,height,background}` + `layers[]`；`LayerBox{x,y,w,h,rotation,flipH,flipV,skewX,skewY}` |
| **`w/h` 是未旋转的内容尺寸** | 旋转由 `rotation` 单独表达。**交换 w/h 会让内容被拉伸**（踩过一次） |
| **两端共用一组六参** | `composeMatrix(box, natural)` → CSS `matrix()` / Rust `AffineMatrix`，两边都不再自行推导 |
| **显示走原文件** | 放大到 100% 看到真像素；Rust 代理图只服务缩略图（与将来的超大图打底） |
| **裁剪非破坏性** | 改画布尺寸 + 图层反向平移，像素不删；导出按画布裁切 |
| **画布旋转是"一次性换算"** | `rotateDocumentCanvas` 只映射中心、角度 ±90，不留文档级 rotation 字段 |
| **调色是图层属性** | 预览 CSS `feColorMatrix`，导出 Rust 同一矩阵；`adjust` 不进代理图缓存键 |
| **EXIF 方向折进变换** | core 手写解析 tag 0x0112 → `orientationToBox` → 图层 img 设 `imageOrientation:'none'` |
| **撤销只存参数** | `{canvas, layers}` 快照；`documentStateSignature` 判变，700ms 内纯调色合并成一步 |

## 3. 能力清单

### 3.1 工具（`available: true`）

| 工具 | 键 | 已实现 |
|---|---|---|
| 移动 | V | 拖图层（`box.x/y`）；**点一下图层才显示选中框**，点画布空白取消 |
| 自由变换 | Ctrl+T | 八向手柄缩放、四角外侧旋转、拖内部移动、吸附到画布四边/中心（可关）、Enter 提交、Esc 还原；选项条有 W/H/角度/±90° |
| 裁剪 | C | 拖框 + 8 个把手 + 比例预设（原始/1:1/16:9/9:16/4:3）；Enter 应用、Esc 取消；**非破坏性** |
| 抓手 | H / 空格按住 | 平移视口 |
| 缩放 | Z | 单击放大、Alt+单击缩小；滚轮=平移、Shift+滚轮=横向、Ctrl/Alt+滚轮=缩放、双击=适应 |

### 3.2 文档级操作（文档栏，贯穿顶部整行）

- 新建空白文档：6 个尺寸预设 + 自定义 + 背景（透明/白/黑）→ **开新标签页**
- 导入图层：任意路径的图片，contain 居中落位，EXIF 方向正确
- 画布 90° 旋转（四向）/ 水平·垂直翻转（一次性换算）
- 撤销 / 重做（Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y）
- 导出：PNG / JPEG / WebP(无损)，**全分辨率**合成；导出后自动重扫画廊
- 缩放百分比、查看全部、左右面板开关

### 3.3 Rust 侧（`aurora_core::imaging` + `editor_commands`）

| 入口 | 作用 |
|---|---|
| `imaging::affine` | `warp_affine` / `warp_into` / `composite`；逆映射 + 双线性；整数落点走最近邻（90° 与 `rotate_image` 逐像素相等） |
| `imaging::exif` | 手写解析 IFD0 tag 0x0112（JPEG APP1 / PNG eXIf / TIFF），零依赖 |
| `editor_load_layer_proxy` | 图层代理（≤2048 JPEG）+ 自然尺寸 + EXIF 方向 |
| `editor_render_document` | 文档合成分辨率预览（超大图打底用，**前端尚未接线**） |
| `editor_export_document` | 全分辨率合成并写盘 |

v1 的三条旧命令（`editor_load_preview` / `editor_render_preview` / `editor_export_image`）已删除。

## 6. 踩过的坑（改这块之前先看这几条）

1. **StrictMode 双跑**：`main.tsx` 开着 StrictMode，任何"只跑一次"的 effect 都必须在清理时复位自己的 ref，且 `cancelled` 不能连带吞掉错误分支——否则表现为"卡在正在打开…"且看不到报错。
2. **`w/h` 不能交换**：定界框里它是未旋转的内容尺寸；v1 的 `rotateCropRect` 交换 w/h 是**轴对齐矩形**语义，照搬会让画面拉伸。
3. **命中判定不能用包围盒**：45° 旋转时包围盒四角是空的，必须 `pointInBox`（反旋到本地坐标）。
4. **EditOverlay 有三个独立开关**：`isEditMode`（能否拖动）/ `showTransformHandles`（手柄与旋转区）/ `showChrome`（蓝框）。共用一个会连坐——移动工具曾因此完全拖不动。
5. **`editor_load_layer_proxy` 的尺寸是存储方向**：浏览器 `<img>.naturalWidth` 是**转正后**的，用它建画布会和导出错位。
6. **改了 Rust 必须完全重启**：`tauri:dev` 是 `--no-watch`，`Ctrl+R` 只刷前端。
7. **脚本改文件要保行尾**：Python `io.open(..., encoding='utf-8')` 默认把 CRLF 读成 LF 再写回，会制造整文件假改动。
