## 1. 一句话状态

**单图层编辑闭环已完整可用**：打开 → 移动/自由变换/裁剪/调色 → 撤销 → 全分辨率导出。
**画布可脱离图**（新建空白文档）、**可叠多层**（导入/渲染/导出），**图层面板已落地**
（列表/选中/眼睛/复制/重排/删除/改名/不透明度/混合模式，见 §3.3）。
**保存已落地**（`.aurora` 工程，存/开成对）：编辑不再"关掉即丢"，但工程里存的是**原图字节**，
§4.5 的降采样/无损重编码策略**尚未生效**（理由见 §5 第 1 条）。

**编辑器的定位**：**桌面端专用**，目标是**尽量还原 Photoshop 的图层功能**（面板布局、快捷键、交互口径都照 PS）。
安卓端走另一套**更简单的编辑**（不复用这里的图层模型）。所以这里**不需要考虑触屏**——
HTML5 拖拽、右键菜单、滚轮/空格这些桌面交互都是一等公民。

## 2. 架构（已定，改动前必读）

```
<视口 overflow:hidden>                       ← 平移缩放、滚轮/空格抓手
  └ <画布容器 w=canvas.w h=canvas.h overflow:hidden 背景=棋盘格|白|黑>
      └ <图层 img src=原文件(convertFileSrc) transform=matrix(a,b,c,d,e,f)>
```

| 事实 | 说明 |
|---|---|
| **文档 = 画布 + 图层** | `canvas{width,height,background}` + `layers[]`；`LayerBox{x,y,w,h,rotation,flipH,flipV,skewX,skewY}` |
| **`w/h` 是未旋转的内容尺寸** | 旋转由 `rotation` 单独表达。**交换 w/h 会让内容被拉伸**（踩过一次） |
| **两端共用一组六参** | `composeMatrix(box, natural)` → CSS `matrix()` / Rust `AffineMatrix`，两边都不再自行推导 |
| **显示走原文件** | 放大到 100% 看到真像素；Rust 代理图只服务缩略图（与将来的超大图打底） |
| **裁剪非破坏性** | 改画布尺寸 + 图层反向平移，像素不删；导出按画布裁切 |
| **画布旋转是"一次性换算"** | `rotateDocumentCanvas` 只映射中心、角度 ±90，不留文档级 rotation 字段 |
| **调色是图层属性** | 预览 CSS `feColorMatrix`，导出 Rust 同一矩阵；`adjust` 不进代理图缓存键 |
| **EXIF 方向折进变换** | core 手写解析 tag 0x0112 → `orientationToBox` → 图层 img 设 `imageOrientation:'none'` |
| **撤销只存参数** | `{canvas, layers}` 快照；`documentStateSignature` 判变（**含图层 id**），700ms 内纯调色合并成一步 |
| **面板缩略图按层按需生成** | `layerProxy.ensureLayerPreview`：并发闸 2、按路径去重、失败不重试；代理缓存上限 16 |
| **工程 = 自包含 ZIP** | `.aurora` 里 `images/<md5>.<ext>` 存源文件**原字节**（v2 图层从不烘焙像素，原字节即无损，顺带保住 EXIF 方向）；同一份内容只存一次 |
| **读工程 = 解压到临时目录** | 图层仍以**文件路径**交给画布（`convertFileSrc`），不走 blob/data URL；解压目录按内容寻址，重开不重写 |

### 3.2 文档级操作（文档栏，贯穿顶部整行）

- 新建空白文档：6 个尺寸预设 + 自定义 + 背景（透明/白/黑）→ **开新标签页**
- 导入图层：任意路径的图片，contain 居中落位，EXIF 方向正确
- 画布 90° 旋转（四向）/ 水平·垂直翻转（一次性换算）
- 撤销 / 重做（Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y）
- **保存 / 另存为工程**（Ctrl+S / Ctrl+Shift+S）：写出 `.aurora` 自包含 ZIP；
  从图库打开的 `photo.jpg` 一定走另存为（不许把工程覆盖到原图上）
- **打开工程**（Ctrl+O，以及**应用顶栏**的文件夹按钮——新启动的应用没有编辑器标签，
  那个入口才够得着）
- **新建文档弹窗开着时，编辑器快捷键全部让路**（含空格）：否则 V/C 会"穿透"弹窗改掉背后的工具
- 导出：PNG / JPEG / WebP(无损)，**全分辨率**合成；导出后自动重扫画廊
- 缩放百分比、查看全部、左右面板开关

## 6. 踩过的坑（改这块之前先看这几条）

1. **StrictMode 双跑**：`main.tsx` 开着 StrictMode，任何"只跑一次"的 effect 都必须在清理时复位自己的 ref，且 `cancelled` 不能连带吞掉错误分支——否则表现为"卡在正在打开…"且看不到报错。
2. **`w/h` 不能交换**：定界框里它是未旋转的内容尺寸；v1 的 `rotateCropRect` 交换 w/h 是**轴对齐矩形**语义，照搬会让画面拉伸。
3. **命中判定不能用包围盒**：45° 旋转时包围盒四角是空的，必须 `pointInBox`（反旋到本地坐标）。
4. **EditOverlay 有三个独立开关**：`isEditMode`（能否拖动）/ `showTransformHandles`（手柄与旋转区）/ `showChrome`（蓝框）。共用一个会连坐——移动工具曾因此完全拖不动。
5. **`editor_load_layer_proxy` 的尺寸是存储方向**：浏览器 `<img>.naturalWidth` 是**转正后**的，用它建画布会和导出错位。
6. **改了 Rust 必须完全重启**：`tauri:dev` 是 `--no-watch`，`Ctrl+R` 只刷前端。
7. **脚本改文件要保行尾**：Python `io.open(..., encoding='utf-8')` 默认把 CRLF 读成 LF 再写回，会制造整文件假改动。
8. **JSON 键名是跨语言契约**：`box` 是 Rust 保留字，两端的结构体都用 `#[serde(rename = "box")]` 把它挂到 `frame` 字段上。漏一个 rename 的表现是"打开工程后所有图层挤在左上角、尺寸 0×0"——不报错、只是画错了。`json_keys_match_frontend_contract` 那条单测就是盯这个。
9. **`doc.path` 不能进 `docIdentity`**：保存会把路径从 `photo.jpg` 换成 `photo.aurora`，身份一变撤销栈当场清空（"刚存完就撤不回去了"）。文档身份只看"画布是否就绪"。
10. **`.aurora` 不是图片**：`needsInit` 的判据必须排除工程路径，否则把**空白文档**存成工程后，`path` 一变就会去解码一个 ZIP（表现为画布上盖一层"无法打开这张图"）。
11. **不可见的图层 Rust 照样合成**：`DocumentRequest` 里根本没有 `visible` 字段，`composite` 只按数组逐层画。所以"关掉眼睛"必须在**前端** `handleExport` 的 filter 里剪掉，否则屏幕上没有、导出里又有（2026-10-24 加可见性开关时一并修）。
12. **`needsInit` 的 `layerCount === 0` 不等于"还没初始化"**：用户把最后一层删掉也会得到 0，初始化 effect 会当场把那层从源文件重建回来（表现为"删不掉最后一层"）。判据要另加一个"已成功初始化过这个路径"的 ref（`initDoneRef`）。注意它**不能**在 effect 清理时复位——复位就退化成 `initStartedRef`。
13. **签名必须含图层 `id`**：两张同源同尺寸的图层（复制出来的）在其余字段上一模一样，只有 id 能区分。漏了的表现是"把副本挪一层"不进撤销栈（这条是单测抓的，不是人肉发现）。
14. **不透明度 = 合成前的 alpha 缩放**，不是"给 `composite` 加参数"：混合是直通 alpha 的 src-over，整层半透明等价于每像素 alpha 乘同一系数。在 `composite` 里乘会**连重采样插值出来的 alpha 也再乘一遍**，边缘发暗。顺序定在「调色之后、重采样之前」。
15. **两个签名各收什么，是刻意的分工**：`layerStateSignature`（撤销"变了没"）要含 `adjust` 与 `opacity`；`layerGeometrySignature`（判断"是不是只在拖滑杆"）**不能**含它们，否则拖一次滑杆灌上百条历史。加新字段时先想清楚它属于哪一类。
16. **同一个控件既要"点一下"又要"按住拖"时，两种手势会打架**：行内不透明度用 Pointer Events + `setPointerCapture`（拖动中途指针移出那个 9 个字宽的小方块也不会断），3px 阈值区分"手抖"与"拖动"；同时这些元素必须打 `data-no-drag`，让父级 HTML5 `onDragStart` 用 `closest()` 把它们挡掉——否则"按住数值左右拖"会变成"拖整行排序"。
17. **带 `transform`/`willChange` 的祖先会吃掉 `position: fixed`**：右面板容器为了滑入动画带 `transform` + `willChange: 'transform'`，外层还有 `overflow-hidden`——面板里任何 fixed 定位的浮层都会**以它为定位基准并被裁掉**（表现为"点了没弹窗"）。面板里的浮层一律 `createPortal` 到 `document.body`。
18. **图层面板的两个"顺序"**：文档里 `layers` 是**自底向上**（下标 0 最先画），面板必须**自顶向下**。反转只在 `layersTopDown` 做一次；谁在别处又 reverse 一次，"上移"就会变成"下移"。

## 7. ImageEditor 防膨胀规则（2026-10-24 立，动工前先看）

现状：`ImageEditor.tsx` 已 1664 行（editor 目录共 ~5900 行）。它**不该**继续长——每加一个
功能块就按下面的边界搬一次，保持它是个**薄编排层**（目标 <500 行）：

1. **纯逻辑 → hook 文件**：键盘快捷键 → `useEditorKeyboard`；滚轮/空格/缩放平移 →
   `useEditorViewport`；裁剪状态机 → `useEditorCrop`；撤销栈 → `useEditorHistory`。
   hook 收状态依赖，返回 handler，ImageEditor 只留一行调用。
2. **成块的 UI → 组件文件**：一段 JSX 有自己的状态或超过 ~50 行就拆（画布渲染段 →
   `EditorCanvasLayers`）。
3. **两端共用的数学/名字表 → 独立 ts 模块**：照 `cropGeometry` / `colorMatrix` /
   `blendModes` 的模式。
4. **搬家的时机 = 顺手**：做完一个功能就把相关逻辑搬走，**不做攒到一起的大重构**
   （搬完 `wc -l` 看 ImageEditor 行数，涨了就说明这轮没搬干净）。
5. 拆分批次（按肥瘦排）：A 键盘 hook → B 视口 hook → C 裁剪 hook → D 历史 hook →
   E 画布渲染组件。
