> 文档版本：v1.0
> 创建日期：2026-08-07
> 状态：设计阶段

---

## 一、背景与目标

### 1.1 现状

当前局域网互联架构是**单向的**：

```
Android ──(HTTP 客户端)──→ 桌面端 (HTTP 服务端)
                              ↑
                      只能浏览桌面端的图片
```

- 桌面端运行 Axum HTTP 服务端（`src-tauri/src/lan_share/`），通过文件系统暴露图片
- 安卓端运行 HTTP 客户端（`src/components/lan-client/`），通过 REST API 浏览桌面端图片
- 安卓端可将本地图片**上传**到桌面端

### 1.2 目标

实现**桌面端连接安卓端**，使桌面端能够浏览安卓设备上的图片：

```
Android (HTTP 服务端) ──→ 桌面端 ──(HTTP 客户端)──→ Android
                        能浏览安卓端的图片
```

### 1.3 功能目标

1. **安卓端启动 HTTP 服务端**，将 MediaStore 中的图片通过 REST API 暴露
2. **桌面端增加客户端连接入口**，输入安卓设备 IP/端口/验证码后连接
3. **双向互联互不干扰**：现有安卓→桌面端连接不受影响
4. **息屏保活**：安卓端在息屏后仍能保持服务端在线
5. **图片浏览与下载**：桌面端可浏览安卓端缩略图、查看原图、下载到本地

## 二、架构设计

### 2.1 整体架构

```
┌──────────────────────────────────────────────────────────────────┐
│                        Desktop (Dual Mode)                       │
│  ┌──────────────────────┐    ┌────────────────────────────────┐ │
│  │  LAN Share Server    │    │  Android Client Connector     │ │
│  │  (现有, 不变)         │    │  (新增)                       │ │
│  │  - 服务桌面端图片      │    │  - 连接安卓端 HTTP 服务         │ │
│  │  - 接收安卓端上传      │    │  - 浏览安卓端图片              │ │
│  └──────────────────────┘    │  - 下载安卓端图片到本地          │ │
│                              └────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────┘
                              ↑
                      HTTP over LAN
                              ↓
┌──────────────────────────────────────────────────────────────────┐
│                    Android (Dual Mode)                           │
│  ┌──────────────────────┐    ┌────────────────────────────────┐ │
│  │  LAN Share Client    │    │  LAN Share Server (新增)       │ │
│  │  (现有, 不变)         │    │  - 基于 MediaStore 的 HTTP 服务  │ │
│  │  - 连接桌面端服务      │    │  - 前台服务保活                │ │
│  │  - 浏览桌面端图片      │    │  - REST API 暴露图片           │ │
│  │  - 上传图片到桌面端     │    │                              │ │
│  └──────────────────────┘    └────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────┘
```

### 2.2 关键设计决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| Android HTTP 框架 | 与桌面端复用同一套 Axum 代码 | 减少重复开发，API 风格一致 |
| 图片访问方式 | 通过 MediaStore ContentProvider | 安卓文件权限限制，无法直接访问文件系统 |
| 设备保活 | Foreground Service + 通知 | 防止 Doze 模式切断网络 |
| 桌面端客户端 | 复用现有 LanClientApi 模式 | 与现有安卓客户端实现对称 |
| 认证方式 | 与桌面端相同的验证码机制 | 用户已熟悉，实现一致 |

### 3.4 API 端点

与桌面端保持一致，便于客户端代码复用：

| 端点 | 方法 | 功能 | 差异说明 |
|------|------|------|----------|
| `/api/auth/verify` | POST | 验证码认证 | 与桌面端一致 |
| `/api/auth/logout` | POST | 登出 | 与桌面端一致 |
| `/api/all_image_folders` | GET | 获取所有含图文件夹 | 基于 MediaStore BUCKET_ID 分组 |
| `/api/browse` | GET | 浏览文件夹内容 | `path` 参数为 BUCKET_ID |
| `/api/thumbnail` | GET | 获取缩略图 | 使用 MediaStore 内置缩略图 |
| `/api/image` | GET | 获取原图 | 通过 ContentResolver 读取 |
| `/api/search` | GET | 搜索图片 | 按文件名/日期搜索 |
| `/api/devices` | GET | 获取连接设备列表 | 与桌面端一致 |
| `/api/heartbeat` | GET | 心跳 | 与桌面端一致 |

### 3.5 前台服务保活

```kotlin
// 新增 Android Foreground Service
class LanShareService : Service() {
    private val server: LanShareServer  // 运行在 Service 内的 HTTP 服务器

    override fun onStartCommand(intent: Intent?, flags: Int, startId: Int): Int {
        val notification = createNotification(
            title = "局域网共享中",
            text = "桌面端可通过局域网浏览本机图片"
        )
        startForeground(NOTIFICATION_ID, notification)
        server.start(config)
        return START_STICKY
    }

    override fun onDestroy() {
        server.stop()
        super.onDestroy()
    }
}
```

**关键点：**
- 使用 `startForeground()` 提供持久通知，防止系统杀死
- 使用 `START_STICKY` 重启策略，异常退出后自动重启
- 通知提供"停止共享"快捷操作
- 可申请 `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` 权限

## 六、息屏保活策略

### 6.1 问题分析

安卓息屏后：
- **Doze 模式**：几分钟后进入，限制网络访问，HTTP 服务端会停止响应
- **Wi-Fi 休眠**：部分机型息屏后 Wi-Fi 进入低功耗模式
- **进程优先级**：普通后台进程可能被系统回收

### 6.2 解决方案

| 策略 | 实现方式 | 效果 |
|------|----------|------|
| **Foreground Service** | 启动时显示持久通知"局域网共享中" | 进程优先级提升，不被 Doze 杀死 |
| **PARTIAL_WAKE_LOCK** | 服务内获取，保持 CPU 运行 | 防止 CPU 休眠导致的网络中断 |
| **忽略电池优化** | 弹窗引导用户授权 | 防止系统限制网络访问 |
| **Wi-Fi 锁** | `WifiManager.WifiLock` | 防止息屏后 Wi-Fi 断开 |
| **心跳检测** | 桌面端客户端检测心跳超时后提示重连 | 优雅处理断连情况 |

### 6.3 用户提示

- 启动共享时弹窗提示："建议将本应用加入电池优化白名单，以保证息屏后共享正常"
- 通知栏显示"桌面端可访问：http://192.168.x.x:8080"
- 通知提供"停止共享"按钮

## 九、未实现/待讨论

1. **上传**：桌面端→安卓端上传目前不在范围内，接入后可以复用现有 upload 逻辑
2. **视频浏览**：MediaStore 中的视频可通过类似方式暴露，但不作为首期目标
3. **多设备同时连接**：安卓端服务端支持多个桌面端同时连接（DeviceManager 已支持），但首期只需验证单设备
4. **Android 端音频权限**：Android 端扫 Fotoo 出一个新服务，需要提醒用户，Android 端扫 Fotoo 会出 Foreground Service 通知
