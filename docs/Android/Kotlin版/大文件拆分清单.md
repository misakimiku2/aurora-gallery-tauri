## 2. 拆到什么粒度

判断标准用**「一个文件是否装了多个职责簇」**，而不是行数：

- 该拆：一个文件里能指出 ≥2 个「各自能独立存在」的簇/类（如 `FileGrid.kt` 装了 4 个类）。
- 不必拆：偏大但单一职责（如 `PersonAvatarCrop.kt` 661 行 = 一个裁剪页，`TopicsOverview.kt` 1552 行 = 一个总览页）。这类拆开收益递减，先不动。
- 目标粒度：**单文件 200–500 行**；超过 ~800 行就该再看一眼。

## 5. 通用手法（两刀跑通，后续照抄）

### 5.1 ViewModel 大类：同包扩展函数

Kotlin 没有 partial class，扩展函数是唯一能「不动结构就把一个类的成员摊到多个文件」的手段：

```kotlin
// GalleryViewModelPeople.kt（与 GalleryViewModel 同包）
fun GalleryViewModel.createLocalPerson(name: String, onDone: (Boolean) -> Unit = {}) { … }
internal suspend fun GalleryViewModel.refreshLocalPeople() { … }
```

要点：
- 同包的顶层扩展**无需 import**，原类也不用改结构。
- 扩展函数内访问 companion 成员要限定：`GalleryViewModel.TAG`（直接写 `TAG` 会报 unresolved）。
- uniffi 的 FFI 顶层函数（`upsertPerson` / `listImagesByIds` / `getFileMetadata` …）在新文件里要**重新 import**，它们不会跟着原文件走。
- 只服务于本簇的私有助手降 `internal`（`private` 跨文件不可见）；对外入口保持 `public`。

### 5.2 搬之前的可见性检查

```powershell
# 对该簇用到的成员逐个确认修饰符，private 的要降 internal
Select-String -Path GalleryViewModel.kt -Pattern '^\s{4}(private |internal )?(val|var|fun|suspend fun) <成员名>\b'
```
原则：能不降就不降；本轮只降了 2 处（`debugLog`、`TAG`），注释里写明「为什么降」。

### 5.3 每刀三步验收

1. `.\gradlew :app:compileDebugKotlin`
2. `.\gradlew :app:testDebugUnitTest`（当前 7 个测试文件 / 59 条）
3. 装到模拟器跑相关页面（`phone35` 起步，必要时再上平板形制）

### 5.4 搬移操作注意

按行区间删除时用**内容锚点**定位起止（不要硬编码行号）；写回保持 **CRLF + 无 BOM**：

```powershell
[System.IO.File]::WriteAllLines($f, $out, (New-Object System.Text.UTF8Encoding($false)))
```
否则整文件 diff 会炸。函数结束行匹配用 `^    \}$`（恰好 4 空格），别用 `^\s*\}$`——那会匹配到循环体的闭合括号。

14. **搬前用脚本穷举可见性依赖（第 8–10 刀一直用，比编译迭代快）** —— 把待搬区间的正文取出来，与原文件里所有 `private` 定义逐个比对，一次就能拿到该降权的清单：
    ```powershell
    $c = [System.IO.File]::ReadAllLines($f)
    $seg = ($c[($start-1)..($end-1)] -join "`n")      # 待搬区间（1-based 闭区间）
    $inSeg = $start..$end
    for ($i=0; $i -lt $c.Count; $i++) {
      if ($c[$i] -match '^\s{4,8}private (val|var|fun|suspend fun|const val) (\w+)') {
        $nm = $Matches[2]; $ln = $i+1
        if ($inSeg -contains $ln) { continue }         # 段内定义会跟着搬走，不算
        if ($seg -match "\b$([regex]::Escape($nm))\b") { "$ln`: $($c[$i].Trim())" }
      }
    }
    ```
    `\s{4,8}` 覆盖成员（4 空格）与 companion 内（8 空格）两种缩进；跑完得到零命中就可以放心搬（第 9、10 刀就是这样确认「零降权」的）。
