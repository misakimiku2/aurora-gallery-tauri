# 设计约定（Kotlin Compose 主题实现参照）

> 版本： v1（2026-08-31）
> 用途： 从桌面端提取设计 token，供 Kotlin 版实现 Compose 主题与组件时照做，保证「与桌面一张脸」。
> 来源： `tailwind.config.js`、`index.css`（581-595 颜色变量等）。
> 原则（规划 §2.3）： **Material 只作技术底座，不作视觉来源**——主题色、组件形状、间距全部以本文件为准，显式覆盖 MaterialTheme 默认。

## 1. 颜色 token

### 1.1 Surface 体系（核心）

桌面端用 CSS 变量 `--color-{main,content,panel,surface,subtle}` 驱动，暗色模式靠 `.dark` 类切换。Compose 侧用 `MaterialTheme.colorScheme` + `isSystemInDarkTheme()` 映射。

| Token | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| main | `#E5E5E5` | `#1A1A1A` | 应用主背景（body/根容器） |
| content | `#FFFFFF` | `#262626` | 内容区（卡片/网格所在层） |
| panel | `#F7F7F7` | `#2A2A2A` | 面板（侧栏/详情面板） |
| surface | `#E5E7EB` | `#3A3A3A` | 表面（次级容器/菜单） |
| subtle | `#E5E7EB` | `#404040` | 细微（分隔替代、浅底） |

### 1.2 主色 / 语义色

| Token | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| primary（主色） | `#3B82F6` | `#3B82F6`（同） | 选中态、按钮、高亮、range thumb、选择框 |
| primary 弱化（选中框描边） | `rgba(59,130,246,0.8)` | `rgba(96,165,250,0.8)` | 选择框/拖拽描边 |
| primary 弱化（选中框填充） | `rgba(59,130,246,0.2)` | — | 选择框背景 |
| 文字主色 | `#1E293B` | `#E5E5E5` | 正文 |
| 次级文字 | gray-500（neutral） | gray-400 | 说明/占位 |

> 注意：桌面端 `#3B82F6` 散落硬编码（未统一变量），本文件将其收敛为单一 `primary` token。

### 1.3 灰色阶（gray = Tailwind `neutral` + 扩展）

| 阶 | 值 | 阶 | 值 |
|---|---|---|---|
| gray-400 | `#A3A3A3` | gray-750 | `#333333` |
| gray-500 | `#737373` | gray-850 | `#1E1E1E` |
| gray-600 | `#525252` | gray-950 | `#0A0A0A` |

## 2. 圆角

| 场景 | 值 |
|---|---|
| 卡片（file-item） | `12dp`（rounded-xl） |
| 大面板/弹层 | `16dp`（rounded-t-2xl） |
| 常规面板/菜单 | `8dp`（rounded-lg） |
| 圆形（按钮/头像） | 全圆（rounded-full） |
| 拖拽高亮目标 | `12dp`（0.75rem） |

## 3. 间距

| 场景 | 值 |
|---|---|
| 网格 gap（平板 ≥600dp） | `16dp` |
| 网格 padding（平板） | `24dp` |
| 网格 gap（手机 <600dp） | `10dp` |
| 网格 padding（手机） | `8dp` |
| 卡片内边距（列表/面板通用） | `16dp`（横向） |

## 4. 毛玻璃菜单配方（多处复用，统一样式）

| 模式 | 配方 |
|---|---|
| 亮色 | 背景 `#FAFAFA` @ 90% 透明度 + `backdrop-blur 12dp`（md）+ 阴影 `0 8 30 rgba(0,0,0,0.12)` |
| 暗色 | 背景 `#3A3A3A` @ 90% 透明度 + `backdrop-blur 12dp` + 阴影 `0 8 30 rgba(0,0,0,0.6)` |

Compose 侧可用 `Modifier.background(Brush.verticalGradient)` 或半透明色 + `Modifier.blur`（Android 12+），或降级为纯半透明色（`Color.copy(alpha=0.9f)`）+ 阴影，避免低版本无原生 blur 而引入第三方库。

## 5. 字体层级

桌面端用 Tailwind 文本类，映射到 Compose Typography（Material3 默认字号，仅调整字重/行高，不引入新字体）：

| 层级 | 用途 | Compose 映射 |
|---|---|---|
| titleLarge（约 20-22sp） | 查看器标题、弹窗标题 | `headlineSmall` |
| titleMedium（约 16-17sp） | 文件夹名、列表主行 | `titleMedium` |
| bodyMedium（约 14sp） | 图片名、正文 | `bodyMedium` |
| bodySmall（约 12sp） | 计数、说明、badge | `bodySmall` |

## 6. 阴影

| 场景 | 值 |
|---|---|
| 菜单/弹层 | 偏移(0,8)，半径 30，亮 `rgba(0,0,0,0.12)` / 暗 `rgba(0,0,0,0.6)` |
| 卡片 hover | 轻微上浮阴影（桌面），触摸端改为按压态（无 hover） |

## 7. 动画 / 缓动

| 动画 | 参数 |
|---|---|
| 弹性入场（zoom/slide） | `cubic-bezier(0.16, 1, 0.3, 1)`，300ms |
| 面板推挤（layout-transition） | `cubic-bezier(0.4, 0, 0.2, 1)`，300ms |
| 淡入 | 200ms ease-out |
| 底部弹层上滑 | 250ms ease-out |
| 侧栏滑入（右） | 300ms ease-out |

Compose 对应：`tween(durationMillis = 300, easing = FastOutSlowInEasing)`（面板）、`tween(300, easing = CubicBezier(0.16f,1f,0.3f,1f))`（入场）。

## 8. 选中态 / 选择框

- 卡片选中：主色 `#3B82F6` 边框 + 20% 主色填充。
- 框选（marquee）区域：`rgba(59,130,246,0.8)` 1px 边框 + `rgba(59,130,246,0.2)` 填充。
- 选中勾选角标：主色圆形 + 白色对勾。

## 9. 安全区 / 状态栏

- 顶部：`env(safe-area-inset-top)` → Compose 用 `WindowInsets.safeDrawing` / `systemBars`。
- 沉浸模式下隐藏系统 UI，退出恢复（对应 M4 全屏，M1 仅 TopBar 预留 insets）。

## 10. 滚动条（Kotlin 侧可简化）

桌面端为隐藏式滚动条（静止淡出、滚动淡入、悬停放大，14dp 宽）。RecyclerView 原生滚动条语义不同，**Kotlin 侧不照搬**，改用系统滚动条或完全隐藏（触摸场景滚动条非必需），此项在 M1 阶段 3 实现时确认。

## 11. Compose 主题实现清单（阶段 3 落地时逐项对照）

1. `AuroraColorScheme(light/dark)`：覆盖 `primary`、`surface`、`background`、`onBackground` 等，映射 §1。
2. `AuroraTypography`：覆盖 §5 四个层级，字重/行高对齐桌面，不引入新字体。
3. `AuroraShapes`：`small=8dp`、`medium=12dp`、`large=16dp`。
4. 毛玻璃组件封装（`AuroraGlassMenu`）：§4 配方。
5. 主色收敛：所有选中/高亮统一走 `primary` token，禁止硬编码 `#3B82F6`。
