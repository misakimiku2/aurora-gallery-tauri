# 安卓端扫码连接功能实现记录

## 概述

本次修改实现了安卓端局域网客户端的"扫码连接"功能，使用户可以通过手机摄像头扫描桌面端局域网共享的二维码，自动完成服务器地址、端口的识别以及访问码认证，实现一键连接。同时修复了摄像头在 Android WebView 中无法启动、扫码界面布局、安卓返回键拦截等问题。

### 功能目标

- **扫码连接**：点击"扫码连接"→ 打开全屏摄像头 → 扫描桌面端二维码 → 自动解析 URL + 访问码 → 自动认证连接 → 保存 token 供下次重连
- **二维码内容**：JSON 格式 `{"type":"aurora-lan","url":"http://...","code":"1234"}`，兼容旧版纯 URL 格式
- **全屏扫描**：摄像头画面铺满全屏，四角指示框提示扫描区域
- **安卓返回键**：扫码状态下按返回键仅退出扫描，不退出设置弹窗
- **安全停止**：摄像头硬件错误时不再崩溃，安全处理扫描器停止逻辑

**safeStopScanner 辅助函数**：

```typescript
function safeStopScanner(s: Html5Qrcode): Promise<void> {
  try {
    const state = s.getState();
    // 仅在 SCANNING 或 PAUSED 状态才调用 stop()
    // 避免摄像头硬件错误后调用 stop() 抛出 "Cannot stop" 异常
    if (state === Html5QrcodeScannerState.SCANNING || state === Html5QrcodeScannerState.PAUSED) {
      return s.stop().catch(() => {});
    }
  } catch {}
  return Promise.resolve();
}
```

### 2. `src/components/lan-client/qrParseUtils.ts`

二维码数据解析工具，兼容新旧格式。

```typescript
export interface ParsedQrData {
  host: string;
  port: number;
  code?: string;  // 访问码（可能不存在于旧格式）
}

export function parseQrData(rawText: string): ParsedQrData | null {
  // 1. 新格式：JSON {"type":"aurora-lan","url":"http://...","code":"1234"}
  if (trimmed.startsWith('{')) {
    const obj = JSON.parse(trimmed);
    if (obj.type === 'aurora-lan' && obj.url) {
      const urlResult = parseServerUrl(obj.url);
      if (urlResult) return { ...urlResult, code: obj.code };
    }
  }
  // 2. 旧格式：纯 URL "http://192.168.1.100:8080"
  return parseServerUrl(trimmed);
}
```

const handleScanResult = useCallback(async (rawData: string) => {
  setScanning(false);
  const parsed = parseQrData(rawData);

  if (!parsed) {
    setError(t('settings.lanShare.client.invalidQr'));
    return;
  }

  setHost(parsed.host);
  setPort(String(parsed.port));

  if (!parsed.code) {
    setError(t('settings.lanShare.client.enterCode')); // 旧格式无访问码
    return;
  }

  // 自动认证连接
  setCode(parsed.code);
  lanClientApi.setBaseUrl(`http://${parsed.host}:${parsed.port}`);
  const res = await lanClientApi.authenticate(parsed.code);
  if (res.success && res.token) {
    // 保存连接信息，完成连接
    onUpdateSettings({ ...saved, serverAccessToken: res.token });
    setConnected(true);
  }
}, [...]);

### 3. `src-tauri/gen/android/.../MainActivity.kt`

**WebView 摄像头权限处理**：

这是摄像头打不开的根本原因——Android WebView 默认拒绝 `getUserMedia` 请求，需要在 `WebChromeClient.onPermissionRequest` 中显式授权。

```kotlin
override fun onWebViewCreate(webView: android.webkit.WebView) {
  webView.webChromeClient = object : android.webkit.WebChromeClient() {
    override fun onPermissionRequest(request: android.webkit.PermissionRequest) {
      runOnUiThread {
        val resources = request.resources
        val granted = resources.filter { resource ->
          when (resource) {
            android.webkit.PermissionRequest.RESOURCE_VIDEO_CAPTURE -> {
              ContextCompat.checkSelfPermission(
                this@MainActivity, Manifest.permission.CAMERA
              ) == PackageManager.PERMISSION_GRANTED
            }
            else -> true
          }
        }
        if (granted.size == resources.size) {
          request.grant(resources)
        } else {
          request.deny()
        }
      }
    }
  }
}
```

**关键点**：`onWebViewCreate` 是 `WryActivity` 提供的回调，在 WebView 创建时触发。在此设置自定义 `WebChromeClient` 来拦截 WebView 的权限请求，对 `VIDEO_CAPTURE` 检查 Android 原生摄像头权限状态后决定是否授权。

## 解决的问题

### 1. 摄像头无法启动

**原因**：Android WebView 默认拒绝 `navigator.mediaDevices.getUserMedia()` 的权限请求。

**解决**：在 `MainActivity.kt` 中重写 `onWebViewCreate` 回调，设置自定义 `WebChromeClient`，在 `onPermissionRequest` 中检查 Android 原生摄像头权限后授权 WebView 的 `VIDEO_CAPTURE` 请求。

### 2. 扫码后应用崩溃

**原因**：扫描成功回调中调用 `scanner.stop()`，同时 `onScanResult` 触发 `setScanning(false)` 导致组件卸载，清理函数再次调用 `stop()`，产生竞态。

**解决**：
- 扫描成功后先设 `scannerRef.current = null`，清理函数检查 ref 为空则跳过
- 新增 `safeStopScanner()` 函数，调用 `getState()` 检查状态后再 stop

### 3. 扫描界面非全屏

**原因**：`QrScannerModal` 渲染在设置弹窗内部，父元素的 CSS（overflow/transform）限制了 `fixed` 定位。

**解决**：使用 `createPortal` 将扫描器挂载到 `document.body`，完全脱离设置弹窗 DOM 树。

### 4. html5-qrcode 扫描框畸变

**原因**：库自带的 `qrbox` 配置会生成遮罩和边角指示器，在全屏布局下出现挤压变形。

**解决**：移除 `qrbox` 配置，改为全帧扫描 + 自定义四角边框指示器。

### 5. 安卓返回键退出设置弹窗

**原因**：`stopImmediatePropagation()` 对同一 window 上的事件无效（target 阶段按注册顺序执行）。

**解决**：改用项目统一的 `__androidBackHandled` 模式，扫码状态下设置标志后 App.tsx 的处理器跳过。

### 6. 状态栏遮挡

**原因**：Android edge-to-edge 模式下状态栏覆盖内容区。

**解决**：顶部栏 `paddingTop: max(16px, env(safe-area-inset-top, 16px))`，底部 `paddingBottom: max(32px, env(safe-area-inset-bottom, 32px))`。

### 7. 摄像头硬件错误导致崩溃

**原因**：摄像头设备错误后扫描器内部已停止，`stop()` 抛出 "Cannot stop, scanner is not running"。

**解决**：`safeStopScanner()` 在调用 `stop()` 前检查 `getState()` 返回值，仅 `SCANNING`/`PAUSED` 状态才执行 stop。
