# 主色调提取流程优化实现记录

## 概述

本次修改将主色调提取从自动触发改为手动触发，优化用户体验，避免在切换到大目录时占用大量CPU和时间。

## 修改日期

2026-03-02

## 问题背景

### 原有逻辑
- 首次设置根目录时，自动将所有图片添加到主色调提取队列并启动后台任务
- 切换到新目录时，同样自动触发主色调提取

### 存在的问题
1. 当目录包含大量图片（如 5000+ 张）时，自动提取会占用大量 CPU 和时间
2. 用户无法控制何时开始提取
3. 影响软件的响应速度和用户体验

#### 2.3 新增事件监听

监听 `color-extraction-progress` 事件，实时更新提取进度：

```typescript
useEffect(() => {
  let unlisten: (() => void) | null = null;

  const setupListener = async () => {
    unlisten = await listen('color-extraction-progress', (event: any) => {
      const progress = event.payload as {
        batchId: number;
        current: number;
        total: number;
        pending: number;
        currentFile: string;
        batchCompleted: boolean;
      };

      if (progress.total === 0) return;

      setIsColorExtracting(true);
      
      // 计算预估剩余时间
      const now = Date.now();
      let estimatedTime: number | undefined = undefined;
      if (progress.current > 0 && colorExtractStartTimeRef.current > 0) {
        const elapsed = now - colorExtractStartTimeRef.current;
        const speed = progress.current / elapsed;
        const remaining = progress.total - progress.current;
        if (speed > 0 && remaining > 0) {
          estimatedTime = remaining / speed;
        }
      }

      setColorExtractProgress({
        current: progress.current,
        total: progress.total,
        estimatedTime
      });

      // 检测批次完成
      if (progress.batchCompleted) {
        setTimeout(() => {
          setIsColorExtracting(false);
          setColorExtractProgress(null);
          loadColorDbStats();
        }, 500);
      }
    });
  };

  setupListener();
  return () => { if (unlisten) unlisten(); };
}, []);
```

#### 2.4 新增手动触发函数

```typescript
const handleStartColorExtraction = useCallback(async () => {
  if (isColorExtracting) {
    await pauseColorExtraction();
    setIsColorExtracting(false);
    return;
  }

  const imagePaths = Object.values(state.files)
    .filter(f => f.type === FileType.IMAGE)
    .map(f => f.path);

  if (imagePaths.length === 0) {
    onShowToast?.(t('settings.noImagesToExtract'));
    return;
  }

  colorExtractStartTimeRef.current = Date.now();
  setIsColorExtracting(true);
  setColorExtractProgress({ current: 0, total: imagePaths.length });

  try {
    const addedCount = await addPendingFilesToDb(imagePaths);
    
    if (addedCount === 0 && colorDbStats && colorDbStats.pending === 0) {
      setIsColorExtracting(false);
      setColorExtractProgress(null);
      onShowToast?.(t('settings.colorExtractionNoPendingHint'));
      return;
    }
    
    await resumeColorExtraction();
  } catch (error) {
    console.error('Failed to start color extraction:', error);
    setIsColorExtracting(false);
    setColorExtractProgress(null);
    onShowToast?.(t('settings.colorExtractionStartFailed'));
  }
}, [isColorExtracting, state.files, colorDbStats, t, onShowToast]);
```

#### 2.6 智能提示信息逻辑

根据当前目录图片数量和数据库状态，显示不同的提示：

```typescript
const totalImagesInDir = Object.values(state.files).filter(f => f.type === FileType.IMAGE).length;
const extractedCount = colorDbStats?.extracted || 0;
const pendingCount = colorDbStats?.pending || 0;
const untrackedCount = Math.max(0, totalImagesInDir - extractedCount - pendingCount);

if (pendingCount > 0) {
  // 有待处理的图片
  hintText = t('settings.colorExtractionPendingHint'); // "有 X 个图片待处理主色调"
} else if (untrackedCount > 0) {
  // 有图片还没加入数据库
  hintText = t('settings.colorExtractionUntrackedHint'); // "有 X 个图片待提取主色调"
} else if (extractedCount > 0) {
  // 全部完成
  hintText = t('settings.colorExtractionNoPendingHint'); // "当前目录所有图片的主色调已提取完成"
} else {
  // 新目录
  hintText = t('settings.colorExtractionNewDirectoryHint'); // "点击按钮开始提取..."
}
```

## 修改后的行为

### 首次设置根目录
- **之前**：自动启动主色调提取，大量图片时占用大量资源
- **之后**：不自动启动，用户可在设置中手动触发

### 切换到新目录
- **之前**：自动启动主色调提取
- **之后**：不自动启动，用户可在设置中手动触发

### 点击图片查看
- **之前**：自动提取该图片主色调
- **之后**：保持不变（单张图片提取很快）

### 从外部拖拽文件
- **之前**：复制文件后不提取主色调
- **之后**：复制文件后自动提取主色调（少量文件，可接受）

### 设置界面
- 显示当前目录图片的主色调提取状态
- 提供手动触发按钮
- 显示提取进度（已处理/总数、百分比、剩余时间）

### 5. 颜色搜索前检测主色调数据

**文件**: `src/App.tsx`

在执行颜色搜索（单色搜索 `color:` 和色调搜索 `palette:`）前，检测主色调数据库是否有足够的数据：

```typescript
const colorDbStats = await getColorDbStats();

const totalImagesInDir = Object.values(state.files).filter(f => f.type === FileType.IMAGE).length;
const extractedCount = colorDbStats?.extracted || 0;

const hasInsufficientData = !colorDbStats || 
  extractedCount === 0 || 
  extractedCount < totalImagesInDir * 0.1;

if (hasInsufficientData) {
  showToast(t('tasks.colorDbInsufficient'));
  return;
}
```

**检测条件**（满足任一即提示用户）：
1. `extractedCount === 0` - 完全没有提取过主色调
2. `extractedCount < totalImagesInDir * 0.1` - 已提取数量少于目录图片总数的 10%

**涉及的搜索入口**：
- TopBar 颜色选择器
- MetadataPanel 色块点击
- MetadataPanel 氛围搜索
