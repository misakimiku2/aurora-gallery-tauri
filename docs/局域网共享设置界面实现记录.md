# 局域网共享功能实现记录

## 概述

本文档记录了极光图库（Aurora Gallery）局域网共享功能的完整实现过程，包括前端设置界面和后端 HTTP 服务器。该功能允许用户在同一 Wi-Fi 网络下的其他设备（手机、平板）访问和管理图库。

## 实现时间

- 前端界面：2026-03-12
- 后端服务：2026-03-12

## 功能特性

### 1. 主要功能
- **总开关控制**：启用/禁用局域网共享服务
- **二维码连接**：生成二维码供移动设备扫描连接
- **访问验证码**：4位数字验证码，验证通过后返回 session token
- **权限控制**：允许/禁止编辑和删除操作
- **访问地址显示**：显示服务器 URL，支持复制和打开
- **已连接设备列表**：显示当前在线的设备
- **自动获取局域网 IP**：智能识别局域网 IP 地址

### 2. 界面设计
界面参考设计稿实现，包含：
- 顶部标题栏带 WiFi 图标和绿色开关
- 左侧二维码区域（144x144px）
- 右侧访问验证码（180px 宽度，深色背景）
- 允许编辑和删除的开关
- 访问地址输入框带复制按钮
- 已连接设备列表（带在线状态）
- 底部提示信息

### 7. 局域网 IP 获取

智能识别局域网 IP 地址，优先级：
1. `10.x.x.x` - A 类私有地址
2. `172.16.x.x` - `172.31.x.x` - B 类私有地址
3. `192.168.x.x` - C 类私有地址

```rust
fn is_private_lan_ip(ip: &Ipv4Addr) -> bool {
    let octets = ip.octets();
    match octets[0] {
        10 => true,
        172 => octets[1] >= 16 && octets[1] <= 31,
        192 => octets[1] == 168,
        _ => false,
    }
}

pub fn get_local_lan_ip() -> Option<String> {
    let all_ips = local_ip_address::list_afinet_netifas().ok()?;
    
    // 优先选择局域网 IP
    for (name, ip) in all_ips {
        if let IpAddr::V4(ipv4) = ip {
            if !ipv4.is_loopback() && !ipv4.is_link_local() {
                if is_private_lan_ip(&ipv4) {
                    return Some(ipv4.to_string());
                }
            }
        }
    }
    // 回退到默认方法
    local_ip_address::local_ip().ok().map(|ip| ip.to_string())
}
```

## 界面优化记录

### 优化 1：访问码宽度调整
- **问题**: 访问码显示宽度不够
- **解决**: 设置固定宽度 `w-[180px]` 并居中显示

### 优化 2：二维码边界框修复
- **问题**: 深色模式下二维码像素超出边界框
- **解决**: 
  - 移除 `dark:bg-gray-900`，保持白色背景（二维码在白色背景上显示最佳）
  - 添加 `overflow-hidden` 防止内容溢出
  - 调整内边距 `p-3`
  - 二维码尺寸调整为 `w-36 h-36` (144px)
  - 添加 `block` 属性确保图片正确显示

### 优化 3：根路由 404 问题
- **问题**: 访问 `http://ip:port/` 返回 404
- **解决**: 添加根路由处理器，返回服务信息 JSON

### 优化 4：IP 地址识别问题
- **问题**: 返回 VPN 或虚拟网络接口的 IP（如 `26.99.118.56`）
- **解决**: 扫描所有网络接口，优先选择局域网私有 IP 地址

### 优化 5：路径解析问题（Windows）
- **问题**: 访问根路径 `/` 时，`PathBuf::join("/")` 在 Windows 上会产生 `E:/` 这样的错误路径
- **原因**: Windows 上 `join` 把 `/` 当作绝对路径处理
- **解决**: 过滤根路径 `/`，将其转换为空字符串
```rust
let raw_path = query.path.unwrap_or_default();
let relative_path = if raw_path == "/" || raw_path.is_empty() {
    "".to_string()
} else {
    raw_path.trim_start_matches('/').to_string()
};
```

#### 解决的问题

1. **Token 传递机制**: 图片查看器中 `<img>` 标签无法在请求头中传递 Authorization header
   - 解决方案: 将 Token 作为 URL 参数传递
   - 修改 `getImageUrl()` 方法添加 token 参数
   - 修改后端 `handle_image` 和 `handle_thumbnail` 支持从 URL 参数提取 Token

2. **路径解析问题**: Windows 上根路径 `/` 处理问题
   - 解决方案: 过滤根路径 `/`，将其转换为空字符串

3. **静态文件编译缓存**: Rust 的 `include_str!` 宏在编译时嵌入静态文件，更新前端后需要重新编译
   - 解决方案: 在 `build.rs` 中添加 `cargo:rerun-if-changed` 指令

4. **UI 风格不一致**: 局域网前端界面与主应用风格不同
   - 解决方案: 统一配色方案和组件样式

## 注意事项

1. **二维码生成**: 当前使用外部 API (`api.qrserver.com`) 生成二维码，需要联网。后续可考虑使用本地库生成。

2. **防火墙**: Windows 防火墙可能需要允许应用通过防火墙，否则其他设备无法访问。

3. **Session 管理**: Session 默认 1 小时过期，每 60 秒自动清理过期会话。

4. **安全考虑**: 
   - 仅监听 `0.0.0.0`，不暴露到公网
   - 需要验证码才能访问
   - 支持权限控制（编辑/删除）
