## 1. 引擎事实(已核验,附出处)

### 1.1 数据模型
- 层树 7 种 `LayerContent`:Raster/Group/Adjustment/Fill/**Text/Shape**/Smart(`doc/src/lib.rs:615,640`)——矢量层与位图层同树共存,我们现有图层面板天然能显示。
- 矢量几何(`doc/src/vector.rs`):`Knot{anchor,in_ctrl,out_ctrl,smooth}`(:26)→`Subpath{closed,knots,op}`(:79)→`Path{subpaths,fill_rule,inverted}`(:118);`PathOp=Combine|Subtract|Intersect|Exclude`(:54);`NamedPath`(:171)/`ClippingPath`(:180)/`VectorMask{path,enabled,linked,density,feather}`(:188)。
- 形状层 `ShapeLayer{path,fill,stroke,live,cache,…}`(:325):`LiveShape::Rect/Ellipse/Polygon/Line`(:296)参数化保留供属性面板再编辑;`ShapeStroke{width,paint,opacity,align,cap,join,miter_limit,dashes,…}`(:234)。**cache=栅格化结果,命令侧自动重刷**。
- 文字层 `TextLayer{text/font_family/size_pt/color/transform/runs/paragraphs/shape/orientation/antialias/warp}`(`doc/src/lib.rs:390`);`TextShape::Point|Box|Path(沿路径)|Area(框内排版)`(`doc/src/text.rs:228`);样式 `CharStyle/ParagraphStyle`(:62,184)。
- 文档路径:doc.paths(命名)+ work path + 层形状路径/矢量蒙版,三处可作钢笔编辑目标。

### 1.2 命令面(engine/src/,全部经 `run()` 通用透传即可)
- **形状**:`shape.create{kind:"rect|roundedRect|ellipse|polygon|star|line|path",…,fill=前景,stroke?,addTo?}`(vector_cmds.rs:1757)→`shape.info`;`shape.edit{layer?,path?/live,move?/transform?,fill?,stroke?,…}`(:1782)。
- **路径编辑**(path_edit_cmds.rs):`path.moveAnchors/moveHandle/bendSegment/convertPoint/addAnchor/deleteAnchor`——目标是 work path/命名路径/`"layer"` 形状层/矢量蒙版。
- **路径面板数据**:`path.list/info/set{name,path,op}/delete/rename`;`path.transform`(路径自由变换);`path.toSelection{feather,antiAlias,mode}`;`select.toWorkPath{tolerance}`;`path.fill/stroke{tool,…}`;`layer.vectorMask.add/edit/fromPath/currentPath/…`;`layer.combineShapes.unite/subtract…`。
- **文字**:`type.create{x,y|box,text,…}`(type_cmds.rs:897)/`type.edit{text|replace|runs,box|point,move?,transform?}`(:925)/`type.setStyle{layer,range,样式键}`(:1048)/`type.info`/`type.fonts`/`type.hitTest`/`type.caret`(文档像素段,竖排/旋转适配,type_caret_cmds.rs:199)/`type.navigate`/`type.attachToPath`/`type.convertToShape`/`type.rasterize`/`type.warpText`/`type.createSelection`(文字蒙版)等。
- **自由变换**:`edit.transform{rect|quad|matrix|scale/rotate/dx/dy,interpolation,target}`(transform_cmds.rs:866)及其 warp/flip 变体;文字编辑中变换=`type.edit{transform}`(并入编辑会话同一 undo 步)。
- **coalesce**:任意命令接受 `"coalesce":"<key>"`,同 key 连续编辑合并为一个历史步(`engine/src/lib.rs:686,226`)——拖拽实时预览/文字编辑会话的历史合并钥匙。**key 生命周期=手势/编辑会话,断线/切层/切换目标必须换 key**。

### 1.3 渲染与字体
- Shape/Text 层走 `layer.surface()→cache`(`compose/src/lib.rs:1523,1558`);**`render_full` 天然包含矢量与文字层**,位图泵零改动;PSD 导入也预烘 cache。
- 字体:`text` crate 内置 Inter/JetBrains Mono + **系统字体目录扫描(Windows 在内,可用 PHOTOCRAFT_NO_SYSTEM_FONTS 关)** + CRAFT_FONTS_DIR 注入;shaping=parley(bidi/换行);**中文靠系统字体回退,壳无需装字体**。注意:`text::shared()` 首次初始化同步扫字体 → 桥层启动时 `warm_shared` 预热,避免首次点文字工具卡顿。
- **文字偏移全是 Unicode scalar 索引非字节**(type_cmds.rs:3-4)——TS 侧必须 `[...string]`/`Intl.Segmenter` 对齐,emoji/代理对是坑。

### 1.4 桥层
- `EditorManager::run()` 已是通用透传(`editor/src/lib.rs:338`),`editor_run` 纯透传——**二期像 M3 一样绝大部分零新桥命令**。钢笔草稿是前端态,提交才发命令(与上游 PenPath 模式同构)。
- 预留(仅性能,后置):4K 复杂形状高频拖动若 `render_full` 卡,仿 `move_hover`/`preview_shape_stroke`(vector_cmds.rs:468,引擎为壳层预留的无调用方 API)加 `pen_preview` 克隆文档局部合成;需在 editor/Cargo.toml 补 `photocraft-vector` 依赖。
- IME:引擎只给几何(`type.caret/hitTest/navigate`);**组字/候选窗/提交时机全在前端**——照上游"preedit 写入文档模型"语义(`type.edit replace` 全量替换组字区间),候选窗定位用隐藏受焦 input/textarea(WebView2 系统 IME 跟随焦点元素,同 Figma/Photopea 惯例)。

## 4. 风险与对策

1. **IME 候选窗定位**(二-6 最大未知):WebView2 系统 IME 跟随焦点元素 → 隐藏 input 绝对定位到 `type.caret` 返回的屏幕坐标(每 preedit/排版变化更新);failure mode=候选窗飘 → 接受系统默认定位,后续再调 TSF。
2. **Unicode 索引**:统一封装 `toEngineIndex(str,tsIdx)`(Intl.Segmenter/[...str]),spec 钉死 emoji/中文混合用例。
3. **coalesce key 生命周期**:封装 per-gesture key 工厂;切层/切工具/换文档/命令失败必须换 key,否则两步并一步。
4. **字体扫描阻塞**:桥启动即后台 `warm_shared`(engine 已暴露则直接调;否则首次 type.fonts 前置)。
5. **性能**:形状 cache 全画布重刷(vector_cmds.rs:462)在 4K+复杂路径高频拖动可能卡 → 先实测,卡再上 `pen_preview` 专用桥命令(克隆文档+damage 局部合成,引擎 `preview_shape_stroke` 范本)。
6. **数位笔**:vendor 无 tablet/gpu crate(壳级),`path.stroke simulatePressure` 只有模拟锥形——与一期磁性压感同口径,可接受。

## 5. 明确不做(上游也从未做/壳级裁剪)

- gpu/tablet crate、artboard、automation(壳级不接);
