# Aurora Gallery 自测指南（非技术人员版）

本指南用于在代码修改后确认应用没有坏。按顺序执行，**每一步看到"预期结果"里的内容就代表通过**。

## 1. 构建检查（最重要，先做这个）

打开"终端"（Windows 开始菜单搜索 `Terminal` 或 `PowerShell`），输入：

```
cd C:\Users\Misaki\Desktop\git\aurora-gallery-tauri
npm run build
```

**预期结果**：屏幕最后出现 `✓ built in xx.xxs`（绿色勾），并且**没有红色报错**。
- 如果出现红色 `error TS...` 字样：构建失败，代码有问题，把报错内容发给我。

## 2. 单元测试

继续在同一个终端输入：

```
npx vitest run
```

**预期结果**：最后出现 `Test Files 1 passed (1)`、`Tests 2 passed (2)`。

## 3. 桌面应用启动测试（冒烟测试）

```
npm run tauri:dev
```

**预期结果**：应用窗口弹出，显示"欢迎界面"（选择图片库文件夹）。第一次启动会较慢（Rust 编译），等 1-5 分钟。

窗口打开后，按下面清单点一遍（这就是"冒烟测试"）：

| 操作 | 预期结果 |
|---|---|
| 选择一个图片库文件夹 | 图片以网格显示出来 |
| 点击一张图片 | 大图预览打开，能放大缩小 |
| 按 `Esc` | 预览关闭 |
| 点左侧"人物"标签 | 人物视图正常显示（空列表也可以） |
| 点"专题"标签 | 专题视图正常显示 |
| 点右上角齿轮（设置） | 设置窗口打开，各选项卡能切换 |
| 关闭窗口 | 应用退出，终端没有红色报错 |

**注意**：`tauri:dev` 会一直占用终端，测试完按 `Ctrl+C` 停止。

## 4. 局域网共享功能抽查（如果改过相关代码）

1. 设置 → 局域网共享 → 开启服务
2. 手机浏览器打开终端里显示的地址（如 `http://192.168.x.x:14422`）
3. 预期：能看到图片列表，能点开大图

## 常见问题

- **`npm run build` 报 `error TS18048` 之类**：类型错误，需要修代码。
- **应用打不开、白屏**：查看终端里 `tauri:dev` 的红色报错，截图发给我。
- **端口被占用**（`EADDRINUSE`）：运行 `npm run clean` 后再试。
- **改了代码后应用没反应**：`tauri:dev` 下改前端代码会自动刷新；改 Rust 代码需要重启（Ctrl+C 再 `npm run tauri:dev`）。
