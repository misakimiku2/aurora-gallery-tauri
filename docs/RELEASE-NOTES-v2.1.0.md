# Aurora Gallery v2.1.0

> 发布于 2026 年 9 月 29 日 · 标签 `v2.1.0` · 桌面 2.1.0 / 安卓 2.1（versionCode 3）

这一版把「第一次打开应用」这件事补齐了。安卓端从零有了一套四步欢迎向导，桌面端从两步扩到四步；顺手把两端互相导流的二维码链路做扎实——扫码直接落到安装包而不是发行页，桌面设置里也补了一条下载入口，平板那张扫不出的码也修到和桌面一样能用。

## 新功能

### 启动欢迎向导

- 安卓端首次有了完整的启动欢迎向导：媒体权限 → 个性化偏好 → AI 服务 → 设备互联四步走完才进主界面，不再一打开应用就裸弹系统权限框。
- 权限被拒时有了兜底页，可一键跳系统设置补授权，不会拒绝一次就永远卡在空网格上。
- 向导按手机与平板两种形态分别排版，浅色深色两档配色，中英随应用语言切换，关键按钮触控目标不小于 48dp。
- 老用户（此前已授权过）升级到本版不会被打断，直接进主界面。
- 桌面欢迎向导从 2 步扩到 4 步：新增「AI 服务」与「设备互联」两步，可当场填服务商 / 接口 / 密钥并测试连接，也可当场开启局域网共享并拿到地址与访问码。
- 新增的两步都提供「跳过」，跳过不写入任何设置；AI 步是草稿式编辑，点「下一步」才落盘。
- 两端步骤指示条都支持点击回退到已完成的步骤。
- 安卓互联步新增「下载桌面端」卡片（说明 + 链接 + 一键复制），与桌面侧的「扫码下载安卓端」对映，两端互相导流。
- AI 服务商三档改成图标 chip：在线 / Ollama / LM Studio，与设置面板同一套叫法。
- 桌面第 2 步去掉了已失效的「点击开始使用后将执行主色调提取任务」提示，跳过按钮文案收短，底栏不再被长文案撑变形。

### 二维码与下载链路

- 桌面「扫码下载安卓端」二维码现在直接指向当前版本安装包，手机扫码即开始下载，不用再进发行页手动挑；取不到直链时自动回退到发行页，不打断向导。
- 桌面二维码从 80px 放大到 144px，并按高分屏提高出图分辨率，加载期间显示转圈占位而不是闪一块空白。
- 平板端二维码加大到与桌面同物理尺寸、补齐四周白边、图案按整数倍逐模块绘制，正常距离就能对上焦。
- 两端二维码与旁边的说明文案改为底部对齐。
- 设置 → 局域网共享在共享未开启时显示「获取安卓端」卡片：一张安装包二维码加一行可复制的地址；开启共享后自动收起，让位给「扫码连接」。
- 安卓欢迎页的下载入口文案与桌面区分开：平板上那颗是「扫码下载桌面端」。

### 设置与图标

- 文件夹图标默认改为 Canvas 版。只影响从没选过样式的用户，此前显式选过经典或简洁的仍按存档走；不支持合成的环境照旧回退到经典版。
- 移除设置里的「调试日志」开关。它服务的是已退役的安卓 WebView 调试链路，留着还会让此前关过日志的用户在没有入口的情况下被永久静默。

## 问题修复

- 修复了安卓平板欢迎页二维码扫不出来的问题（物理尺寸不到桌面一半 + 缺白边）。
- 修复了平板二维码白边明显比桌面端宽、两端观感不一致的问题。
- 修复了安卓手机竖屏欢迎页品牌横幅吃满整卡高度、内容区与底栏被挤出屏幕的问题。
- 修复了安卓手机端描述文字与步骤条贴在一起的问题。
- 修复了安卓平板欢迎向导内容上下贴边、按钮贴着卡片下边缘的问题。
- 修复了安卓端 AI 步填的服务地址不生效（点下一步没提交）的问题。
- 修复了安卓手机端欢迎页仍绘制装饰背景、卡片带多余圆角与投影的问题（改为全屏）。
- 修复了桌面欢迎页第 3 步选「在线」档时三个输入框把底部按钮挤出卡片的问题。
- 修复了桌面欢迎页 Logo 投影显示成方形的问题。
- 修复了桌面二维码加载完成后转圈收不起来的问题——图片命中缓存时（二次进入面板、热更新重挂载）会一直转，桌面三处二维码一并修掉。

> 本版与 v2.0 是同一把签名，安卓**直接覆盖安装即可**，不用卸载。
> 改动集中在启动欢迎向导与扫码下载链路，其余功能未动。
