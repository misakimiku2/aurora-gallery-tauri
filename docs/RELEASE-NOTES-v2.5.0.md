# Aurora Gallery v2.5.0

> 发布于 2026 年 11 月 5 日 · 桌面 2.5.0

这一版的主题是**全新图片编辑器（编辑器 v3）**：图层、14 个工具、16 种调整层、图层蒙版、Select and Mask、Live 渐变、历史记录与 .psd 分层保存——从引擎到界面整套落地，并在此之上做了一轮内存治理：编辑器按需加载、交互期低分辨率预览、关闭编辑器后各进程真正回落。图库侧同步修掉了两处常驻缓存的漏洞。

## 全新图片编辑器

### 工具

- 14 个工具：移动、矩形/椭圆选框、套索 / 多边形套索 / 磁性套索（边缘吸附 + 检测宽度/对比度/频率可调）、裁剪（比例预设 + 拉直 + 角度吸附）、吸管、画笔（软硬度/不透明度/流量）、橡皮擦、渐变、油漆桶、模糊、锐化、涂污、抓手；空格临时抓手、`[` `]` 调笔径、⇧ 约束。
- 精确十字光标：自绘黑影白芯双色光标，Windows 深色主题下浅色画面上也看得清（原生 crosshair 会跟系统变纯白）。
- 选框 / 套索族选项条提供「选择并遮住…」按钮入口，不依赖可能被显卡 / 录屏工具抢占的 Ctrl+Alt+R 快捷键。

### 图层与调整

- 图层系统：像素层 / 15 种调整层 / 渐变填充层 / 图层组，混合模式、不透明度、可见性、重排、缩略图实时刷新。
- 16 种调整层全部带参数编辑器：亮度/对比度、色阶、曲线（含铅笔手绘 + 通道）、曝光度、自然饱和度、色相/饱和度（六色范围）、色彩平衡、黑白、照片滤镜（20 预设）、通道混合器、反相、色调分离、阈值、渐变映射（预设分组）、可选颜色、颜色查找（8 内置）。
- 图层蒙版：链接态壳、灰度查看、蒙版上直接画笔涂抹；像素蒙版密度/羽化调节。
- 拖动滑杆/渐变参数按 100ms 节流提交并 coalesce 成一步历史，撤销深度语义与 PS 一致。

### 选择并遮住（Select and Mask）

- 七种预览视图：洋葱皮 / 蚂蚁线 / 叠加 / 黑底 / 白底 / 黑白 / 在图层上，每视图独立不透明度。
- 全局精修参数：半径、智能半径、平滑、羽化、对比度、移动边缘、采样所有图层；确认时一步 `Select and Mask` 历史，预览期零文档改动。
- Refine 边刷：R 开关、Alt 反向（扩展检测 / 恢复原始边缘）、`[` `]` 调直径、可清除笔刷笔划；画布圆环光标随 Alt 即时切换。
- 对话框标题栏可拖拽，位置跨开合与重启记忆，首次打开居中于画布；切换标签页 / 打开设置页时自动隐藏、回来恢复。
- 触发反馈走编辑器内轻量 toast（底部居中，2.6s 自动消失）：边刷开启提示、快捷键被系统热键占用时的说明等。

### 渐变

- Live 渐变图层（PS 同款）：画布上直接拖出方向线，端点 / 色标 / 中点 widget 实时编辑——拖手柄、沿线移动色标、拖离撕离删除、点击加标、双击取色；径向 / 角度 / 反射 widget 形状保真。
- 渐变编辑器面板：颜色 / 透明度停靠点条带（上=透明度、下=颜色）、拖出撕离、中点调节、与引擎 Ramp 同公式渲染；选项条渐变预设色板弹层 + 预设双击建层。
- 经典渐变模式保留（直接涂在活动层 / 蒙版）。

### 面板与画布

- 右侧四组面板（颜色 / 属性 / 导航器 / 图层）可拖调高度、可折叠；高度模型重构——收起任意组后分隔条依然可调、图层组恒弹性吸满剩余高、页脚钉在底边。
- 取色窗随面板高度自适应；渐变面板精简为取色窗 + 条带（预设走选项条）。
- 原生 `<select>` 下拉全部统一为毛玻璃 EditorSelect（分组、勾选态、键盘 Esc、外点关闭），裁剪比例 / 渐变预设 / 图层混合等 9 处一致。
- 历史记录面板、导航器（红框视图 + 缩放）、信息面板（指针坐标 + RGB 取色，不做无谓刷新）。
- Ctrl+S 覆盖原图并写同名 `.psd` 分层伴生（引擎原子写，失败不毁旧文件）；另存为按扩展名真重编码；快速导出当前图层为 PNG；重开编辑过的图自动恢复图层（伴生 PSD 优先）。
- 复制 / 粘贴与 OS 剪贴板互通：自家镜像保住原位与整层信息，外部新图自动导入并居中。

### 内存治理（这一版重点）

- **编辑器非常驻**：浏览图库时不下载、不解析编辑器代码，首次点「编辑图片」才加载。
- **交互期低分辨率预览**：拖调整滑杆 / 渐变时画布按视口分辨率实时预览，松手立即恢复全分辨率。36MP 图实测交互帧从 144MB/帧 降到 ~5MB/帧（约 30 倍），GPU 进程不再被高频全幅上传撑大。
- **历史预算 2GB**：引擎历史快照默认 8GB 字节预算对大图形形同虚设，改为 2GB——超出自动丢弃最旧历史（50 步上限不变）。
- **关闭编辑器真回落**：修复磁性套索像素快照与剪贴板持整份文档不释放的残留；前端离屏画布位图归零（隐藏的编辑标签页同样释放）；36MP 图关闭后 10 秒原生进程 -156MB、渲染进程 -287MB、GPU/管理器进程 -965MB。
- **WebView2 低内存目标**：关闭最后一个编辑标签页时调用官方 MemoryUsageTargetLevel 让 GPU/管理器进程主动向操作系统归还内存（旧版 Runtime 不支持时静默跳过）。
- **图库侧缓存修复**：对比模式选区缩小时释放原图 + 7 级 mipmap 缓存（此前每张 24MP ≈ 200MB 常驻）；JXL/AVIF 查看缓存从 base64 字符串改为 blob（最坏情况省 ~500MB JS 堆）。

## 问题修复

- 修复 Ctrl+Alt+R 无反应的报障路径：快捷键被系统热键（Intel 显卡 / 录屏 / 剪贴板工具常占）抢占时，选项条按钮仍可打开 Select and Mask。
- 修复渐变 Live 预览「拖动手柄像素过好一会才变、大幅拖动松手后闪回原位再跳回」：位图渲染改完成序泵（永不取消、永远追最新）+ 提交在途背压 + 抬笔 hold 态防闪回。
- 修复收起右侧面板一组后拖分隔条出现反向怪动：面板高度模型重构（分隔条直接调整上方组、折叠组不参与转移、溢出按比例压回）。
- 修复渐变面板最低高时取色窗与渐变条重叠（flex 链误加 min-h-0 导致盒子被压到内容最小高以下）。
- 修复取色窗 SV 方块不随面板高度变化。
- 修复右键「编辑图片」后连续手势偶发整树卸载黑屏（hook-after-early-return）。
- 修复导航器红框 / 信息面板取色在编辑空闲期的无谓 GPU 开销。
