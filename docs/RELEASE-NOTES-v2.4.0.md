# Aurora Gallery v2.4.0

> 发布于 2026 年 10 月 22 日 · 标签 `v2.4.0` · 桌面 2.4.0 / 安卓 2.4.0（versionCode 8）

这一版的主线是视频。它第一次和图片一样是这个库里的正式一员：一起扫描入库、一起排列、有封面、有时长、能筛能播，桌面和手机两边都能直接点开看。围绕这条主线，桌面补齐了播放器和整套播控键位，手机把查看器重做成触屏该有的样子（自动全屏、手势调亮度和音量、双行播控），局域网把视频一并带到对面那台设备上。

## 新功能

- 桌面收下了 12 种视频格式（mp4 / mov / m4v / webm / mkv / avi / wmv / flv / mpg / mpeg / 3gp / ts），和照片混在同一片瀑布流里浏览，文件夹计数、专题、画布都算它一份。
- 每张视频卡片有了自己的封面帧，右下角挂时长角标——一屏扫过去能分清哪一格是视频、大概多长。
- 桌面查看器直接播视频：播放暂停、前后 5 秒、逐帧、倍速、音量、循环都在控制条上，拖进度条画面实时跟着走，不用等松手才跳。
- 播视频时键盘重新排过：← → 是快退快进，翻上一张下一张换到 `[` `]`，空格管播放暂停，图片那套键位没动。
- 桌面右侧面板可以就地开一个小播放窗：不用离开当前这一屏就能先看一眼，带迷你控件、空格控制，打开查看器时它自己让开。
- 幻灯片走到视频会真的播起来，不再停在一张封面上；右键「生成缩略图」也对视频生效。
- 桌面上看到喜欢的那一帧，可以就地复制成图片用。
- 桌面全屏是深色影院态：工具条静止一会儿自己收起，鼠标一动就回来。
- 桌面顶栏新增「媒体类型」筛选（全部 / 仅图片 / 仅视频），和日期、标签筛选叠着用，每个标签页各记住自己那一档。
- 桌面设置里多出「视频」这一类：悬停预览的开关、以及可选的 FFmpeg 组件都在这儿。
- FFmpeg 组件装了它，12 种格式的视频都能出封面帧；不装也有 mp4 / mov / m4v / webm / mkv 这一路封面，其余格式（avi / wmv / flv 一类）只显示占位图标。下载约 164 MB，进度在设置面板和左侧栏底部都跟得到，可暂停可取消，装好后还能重新下载；电脑上本来就有 ffmpeg 的话会直接拿来用。
- 视频的详细信息补齐帧率、码率、编码、旋转，卡片副标题与图片统一成尺寸。
- 手机上视频第一次进本地库：与图片混排、按视频真实比例占位、点开即播，纯视频的相册不再是灰块。
- 手机的视频播放器按触屏重做：进视频自动全屏并转成影院黑底（状态栏和底部手势区背后那层一起转黑），单击画面显隐工具条、起播两秒后自己收起；播控排成上下两行，上行是进度条，下一条／播放／上一条居中在下方。
- 手势全给了画面：横滑调进度、左半屏竖滑调亮度、右半屏竖滑调音量、双指捏合缩放；画面有 1:1 / 适应 / 拉伸 / 裁切 四档，倍速有 0.5 到 2 的五档，倍速与循环跨视频记住。
- 长片的横滑改成两段式慢搜：满屏一滑不再等于整条时间轴，先粗调到位再细调，两分钟内的短片手感和以前一样。
- 手机的视频卡片、点开那一屏、抽屉预览三处都吃封面帧；停在想留的那一帧可以直接「从当前帧设为封面」，清缓存也不会丢。
- 手机的视频详情补齐了桌面那套「更多详情」，详情文字也整体抬大一档。
- 手机解不开的格式现在干脆不出现：AVI / WMV / ASF / FLV 既不进本地列表，也不进局域网列表，不会再碰到一张点得开却报错的灰卡片。
- 局域网把视频带到对面：手机连桌面能直接播共享库里的视频，手机自己当服务端时同样共享视频；字节面改成流式加断点续传，上百 MB 的录屏不必先整只读进内存，拖进度是精确续传而不是重下一遍。
- 手机看局域网里的视频，每次起播要吃掉的流量从几十 MB 压到几 MB。

## 问题修复

- 修了共享过去的视频「没有宽高和时长」——卡片全排成正方形、屏幕录制的封面被裁、时长角标一片空白，这三处是同一个成因：索引那一支只认图片。
- 修了局域网共享目录里根级散放的文件和「只有视频的文件夹」整个看不见的问题，桌面服务端和手机侧栏各有一处成因，两端都升级才完整。
- 修了两个 mp4 容器的老毛病：一种是从别处下回来的长片只肯放开头几分钟、往后拖就定格，另一种点开要干等十几秒（实测从 17.9 秒降到 0.13 秒）。现在扫描时自动就地理顺，只往那一个 box 头上写 4 个字节、不搬一帧画面、文件体积不变，样本片修完用 ffmpeg 逐帧核过，帧数和时长与修前逐字一致。
- 修了视频封面一旦空白就永远不再补、选帧专挑暗场、竖拍视频的封面被拉伸变形。
- 修了 AVI 时长误报成 00:00，以及这个错数字被写进库。
- 修了「用系统播放器打开」只是跳到文件夹、并没有真的把播放器拉起来。
- 修了桌面全屏期间的两处：拖顶部工具栏会把整个全屏一起挪走；硬件视频层盖住工具条、移动鼠标也唤不回来。
- 修了在输入框里打字会误触发静音和全屏、按 Delete 误删文件。
- 修了手机端视频之间翻页残留上一条的画面、以及要按两次才播下一条。
- 修了手机端拖进度条反复闪缓冲转圈、长片横滑一下跳十几分钟。
- 修了手机端几处布局毛病：竖屏两颗键压住下一条视频、「更多」菜单先在下方冒出来再往上窜、藏状态栏那一下画面整个上下跳、从详情返回后影院黑底掉了色。
- 修了旋转过（竖拍）的视频取不到封面、起播瞬间画面纵向拉伸、换片后残留上一条的时间、片尾偶发闪退。
- 修了视频被当成图片去跑 AI 分析、找相似、读位图——这些入口对视频一律不再出现。
- 修了侧栏人物区与标签预览把目录节点当成资源根，导致封面每回都重抽一遍、还在磁盘上留下一个游离的缓存目录。
- 修了从局域网存下来的图片主色调一直不落库（三处自上线就没跑通的问题，含一处同线程死锁）。

> 本版与 v2.3.0 是同一把签名，安卓**直接覆盖安装即可**，不用卸载。
> 视频这条线要两端配套：手机看桌面共享的视频，桌面也请一起升到 2.4.0——旧桌面不下发视频的宽高与时长，手机上会排成正方形、也没有时长角标。
> 能不能播还取决于设备的解码器：桌面上 mp4 / mov / m4v / webm / mkv 在应用内播，avi / wmv / flv / ts 这些会提示交给系统播放器（装了 PotPlayer、VLC 之类就能放）；手机上放行表内的容器仍可能因为片子里是冷僻编码而播放失败。
