# Aurora Gallery v2.2.1

> 发布于 2026 年 10 月 9 日 · 标签 `v2.2.1` · 桌面 2.2.1 / 安卓 2.2.1（versionCode 6）

这一版的主线是「把别人的库搬进来」。PixCall 与 Eagle 两个第三方图库的迁移链路从零落地：不只是读它们的标注，而是连文件夹层级、专题（智能夹）、封面与来源网址一起接管过来，导入前先告诉你这个库能不能命中当前资源根。顺带把「一张图有多个来源网址」这件一直含糊的事做实了——多值存储、就地编辑、导入追加而不是互相覆盖。安卓端这一版集中在人物栏（头像裁剪与筛选排序）、查看器全屏与系统栏，以及国产 ROM 上的文件操作正确性。

## 新功能

### PixCall 库迁移

- 新增 PixCall 库迁移：快照解码、分类、层级重建与断言一整套走通，导入记录落在 `import_records` 表里，可重复导入、可追溯。
- 两个入口：启动欢迎第 1 步新增「使用 PixCall 库」，扫完自动探测并导入；设置 → 存储面板新增整宽折叠卡，服务存量用户与换库用户。
- 迁移界面收尾：库列表只显示文件夹名，导入报告改用数字徽章呈现结果。
- 专题规则拍板落定：删除父专题时级联删除子专题；PixCall 同名看板改为并入已有成员而不是再建一个。
- 导入出来的专题补上封面——此前「归入成员时取首图」那条规则只在前端，导入器绕过了它。

### Eagle 库迁移

- 新增 Eagle 库导入：五个 `eagle_*` 命令、按文件名+扩展名匹配、导入报告列出未匹配项，欢迎页「使用 Eagle 库」来源卡片一并接入。
- Eagle 是复制式库，导入走 C 档「连文件一起接管」：硬链接优先，已经认亲命中的文件不搬动，文件夹树镜像过来。
- 智能夹（Smart Folder）按条件自算成员，没有 `imageCount` 也能算出正确结果；空条件一律跳过；智能夹的描述写进专题描述。
- 专题层级收敛：被跳过的智能夹祖先保留为容器专题，三级及更深的层级压到二级；重跑导入幂等，不会再造一份重复专题。
- 欢迎页第 1 步的来源按钮补齐间距，Eagle 换成官方单色图标。

### 资源库接管

- 资源根目录旁新增「历史」按钮，一键切回此前用过的根目录，不必再翻文件夹选择器。
- 导入 PixCall 库时若当前资源根与该库无包含关系，可直接切到该库再导入；切根统一走确认弹窗（手动换根与此处共用，欢迎页首次设置根不使用）。
- 库卡片的切根说明收回卡内，并补上「包含于当前根」的徽章标识。
- 库不在资源根下时提前提示：选库那一步就能看到命中率预警，不用等导入完才发现没匹配上。

### 来源网址改多值

- 一张图支持多个来源网址（存储改为 JSON 数组，旧的单值数据读时自动兼容，无需迁移）。
- 来源网址可就地编辑：点铅笔进入编辑，回车保存、Esc 放弃，输入区高度随内容自适应。
- 导入语义从「让位」改为「追加」；导入报告中来源网址有新增时明确写进备注。
- 安卓端同步跟上多值：FFI、详情抽屉与局域网共享三处一致。

### 安卓端：人物栏

- 人物栏移植桌面端手动那一半：真实头像、筛选、排序分组，以及全新的头像裁剪页。
- 头像改走原图裁剪，双指缩放绕指尖；裁剪页候选区可上滑展开（带搜索框），视口与遮罩对齐桌面端的 400/250 口径。
- 页面级拖拽滚动条覆盖文件夹 / 标签 / 专题 / 人物四页，人物快照改为启动即加载。
- 总览新增「操作过就排前面」排序，并归一根目录文件夹名字（EMUI 会返回不一致的名字）。

### 安卓端：查看器全屏与系统栏

- 查看器系统栏改为会话模型：进入退出零位移，状态栏常驻，底部抽屉不再露边。
- 针对性收官 EMUI 的三处观感问题：手势面板异色块、标题跳动、顶部碎片；低版本系统的毛玻璃自动降级。

## 问题修复

### 桌面

- 修外部链接在 Tauri 下唤不起浏览器（改为走 `openExternalLink`）。
- 修查看器翻页后永远停在缩略图：迟到的缩略图不再覆盖已上屏的高清图。
- 修切根后局域网共享的根路径没有热更新，导致手机端网络栏只见文件夹不见图片。
- 修只建了空专题也被算作「有东西可迁」。
- 移除 `.pixcall` 的索引豁免：点目录一律跳过，三处判定收敛为同一函数。
- 文件夹时间排序改为取内容最新时间，封面缩略图随排序变化（桌面与移动一致）。

### 安卓

- 修复制误删原图：File 分支后台收尾里的「删源」只属于重命名/移动，复制绝不删源。
- 修复制失败的根因（部分机型 `insert` 返回 null 却不抛异常），复制与删除现在即时可见。
- 修复制/移动偶发全部失败：不再赌 `isExternalStorageLegacy`，改由 File 原语的实际操作结果说话，并补上全链路诊断日志。
- 文件操作改为乐观更新并后台化：物理落盘即算成功，媒体库登记、迁移与旧行清理后台完成。
- 修 Android 10 上的文件操作：targetSdk 29 传统视图 + Q 文件路径原语。
- 修启动崩溃（总览封面重算的属性声明写在了 init 之后）。
- 修候选抽屉内容「啪地跳出」与「操作时突然弹回」，改为交叉淡入与跟手手势。
- 修手机欢迎向导状态栏与窗口背景同色、旋转时重涂。
- 修全新安装后写权限无人请求的问题；调试构建统一使用正式签名，调试日志镜像到外部存储。
- 修来源网址弹窗新增的行看不见（ScrollView 高度算错）。
- 查看器顶栏的旋转按钮改为钉屏方向切换（可锁定横屏查看）。
- 复制/移动目标选择器顶部新增相册搜索框。

### 性能

- 安卓冷启动提速：`file_index` 增加复合索引，大库上文件夹列表可见时间大幅缩短。

## 其它

- 工程侧：定稿双机 SMB 开发环境（cargo target 本地重定向、vite 轮询、tauri dev 关闭监听）；删除已过时的 `memory/` 与 `plan/` 两个历史目录，文档入口统一指向 `docs/`。

> 本版与 v2.1 是同一把签名，安卓**直接覆盖安装即可**，不用卸载。
> 桌面端升级后首次启动会按新的来源网址多值结构读取，旧的单值数据自动兼容。
